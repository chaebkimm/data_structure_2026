# Module 14 — Stage A: Records and Changing Groups

Complete one initial prompt before opening later material.

- `inquiry_prompt.md` is the standard format.
- `inquiry_prompt_linear.md` has the same targets in a linear format for a
  screen reader—software that reads on-screen text aloud—keyboard navigation,
  or speech input.

Reason about separate record cards joined by arrows and a roster whose groups
change as accepted relationships arrive. Invent rules for taking out one card
without losing later cards, combining two groups, and recognizing when a new
relationship changes nothing. Preserve your initial reasoning before Stage B.
Drawing quality and speed are not assessed.
