# Module 4 — Stage E: Lab and Evidence

Start with `student/lab.md`, then edit only:

- `code/starter/int_stack.c`;
- `code/starter/expression_evaluator.c`; and
- `code/tests/test_student.c`.

The public headers and supplied core tests establish the required behavior.
Implement the caller-owned fixed integer Stack, then the checked single-digit
`+`/`*` evaluator. The Stack-Top Autopsy is an isolated intentionally faulty
program; predict its result before running it and do not treat it as starter
code to repair.

Submit the files and evidence listed in the lab. This package intentionally
excludes the reference solution, instructor materials, and extension tests.
