# Module 4 — Stage D: Textbook and Stack Models

Open these materials only after completing and preserving the Stage C core.

- `textbook.md` is the English textbook.
- `textbook_korean.md` is the Korean edition of the same chapter.
- `diagrams/stack_models.md` supplies physical and logical models with exact
  text equivalents.

Choose either textbook language; reading both is optional. Both editions
develop the top-only rule, downward-growing character stack, and the
`1-2*3+4` → `123*-4+` → `-1` expression pipeline in `lab.c`.

The runnable source, driver, and build files mentioned in the textbook arrive
in Stage E. Paths beginning with `student/` or `code/` refer to that lab
package's root, which has the same layout as the module in the repository.

Add corrections beside preserved initial work instead of erasing it. This
stage does not contain the Stack-Top Autopsy answer, instructor tests, or
instructor materials.
