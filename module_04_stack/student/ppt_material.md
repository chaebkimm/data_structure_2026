# 쌓아놓는 형태의 자료구조

- 데이터를 저장해놓고 가장 최신 데이터만 읽거나 제거하는 방식이다.
- 데이터를 추가하거나 삭제할 때 기존 데이터들은 영향을 받지 않는다.

# 스택을 리스트로 구현하기

- 리스트에 데이터를 추가할 때 가장 끝에 추가한다.
- 리스트에서 데이터를 읽거나 삭제할 때 마지막 데이터만 읽거나 삭제한다.

# 데이터 추가하기

- `top`은 마지막 데이터의 인덱스다. 빈 스택에서는 -1이다.
- `top`을 하나 증가시킨 뒤, 새 위치에 데이터를 저장한다. (`stack[++top]`)
- 데이터 개수는 `top + 1`이다.

# 데이터 삭제하기

- 마지막 데이터는 `stack[top]`에 있다.
- 현재 `top` 위치의 데이터를 읽은 뒤, `top`을 하나 감소시킨다. (`stack[top--]`)
- 배열의 값은 지우지 않는다. 줄어든 `top`이 현재 데이터의 범위를 정한다.

# 현재 lab.c의 스택 표현

- 코드 읽기 순서는 [실습 강의 원본](ppt_lab_material.md)을 따른다. 배열 스택, 우선순위와 `switch`, `while`과 `&&`, 변환, 계산 순서다.

- `int stack[10]`과 전역 `top`을 변환과 계산에 함께 사용한다.
- `push(int data)`는 `stack[++top] = data`로 인덱스를 늘린 뒤 저장한다.
- `peek()`는 `stack[top]`을 읽고, `pop()`은 `stack[top--]`로 읽은 뒤 인덱스를 줄인다.
- 유효한 범위는 `-1 <= top < capacity`다. 데이터는 0부터 `top`까지 있고 개수는 `top + 1`이다.
- `is_full()`은 `top + 1 == capacity`, `is_empty()`는 `top == -1`을 확인한다.
- 두 함수는 상태만 알려준다. 가득 찼을 때 push하거나 비었을 때 peek/pop하지 않도록 호출자가 확인한다.

# 연산자 우선순위와 switch

- 기다리는 연산자를 먼저 계산할지 판단하려면 우선순위를 비교해야 한다.
- `prec`는 `switch`로 연산자를 구분한다. `*`, `/`, `%`는 2, `+`, `-`는 1, 나머지는 0을 반환한다.
- 같은 결과를 쓰는 연산자는 `case`를 이어서 적는다. 각 경우의 `return`은 함수를 끝낸다.

# 반복 조건 읽기: while과 &&

- `while`은 본문을 실행하기 전에 조건을 확인한다. `while (!is_empty())`는 스택에 데이터가 있을 때만 읽고 꺼낸다.
- `c >= '0' && c <= '9'`는 두 비교가 모두 참일 때 숫자로 판단한다. 첫 비교가 거짓이면 두 번째 비교는 실행하지 않는다.
- `break`는 가장 가까운 반복문을 끝낸다. 변환 함수의 연산자 반복문을 끝내도 바깥의 입력 읽기는 계속한다.

# 변환 단계: 빈 스택 확인하기

- 입력은 `eq[8]`, 출력은 `postfix[8]`이다. `convert_to_postfix()`는 입력의 `'\0'` 직전까지 읽는다.
- 지역 출력 위치 `pos = 0`, 전역 `top = -1`로 시작한다. 스택은 비어 있다.
- 숫자는 바로 `postfix`에 쓴다. 연산자는 우선순위를 비교한 뒤 스택에 넣는다.
- `while (!is_empty())`가 참일 때만 `peek()`로 기다리는 연산자를 읽는다.
- 기다리는 연산자의 우선순위가 더 낮으면 `break`로 이 반복문을 끝낸다. 같거나 높으면 pop하여 출력에 쓴다.
- 반복문이 끝나면 새 연산자를 push한다. `break`는 바깥의 입력 읽기 반복문까지 끝내지는 않는다.

# 변환을 끝내고 종료 문자 쓰기

- `1-2*3+4`에서 연산자는 최대 두 개가 쌓인다. `-`, `*`가 기다릴 때 `top`은 1이다.
- `+`를 만나면 `*`, `-`를 차례로 꺼내 쓴다. 스택이 비면 반복문이 멈추고 새 `+`를 넣는다.
- 입력을 다 읽으면 남은 연산자를 모두 꺼내 쓴다. 출력은 `123*-4+`, `pos`는 7, `top`은 -1이다.
- 이어서 `postfix[pos++] = '\0'`으로 문자열을 끝낸다. `postfix[7]`에 종료 문자가 쓰이고 `pos`는 8이 된다.
- 종료 문자는 스택에서 꺼낸 값이 아니다. 별도 대입문으로 쓴다.

# 계산 단계: 같은 정수 스택 재사용

- `eval_postfix()`는 전역 `top = -1`로 초기화하고 같은 `int stack[10]`을 숫자와 중간 결과에 사용한다.
- `postfix[i] != '\0'`인 동안 읽는다.
- `push(c - '0')`로 문자 숫자를 정수로 바꿔 넣는다.
- 연산자를 만나면 오른쪽 피연산자 `num2`를 먼저 pop하고 왼쪽 `num1`을 pop한다.
- `calc(num1, num2, c)`의 결과를 다시 push한다.
- `123*-4+`는 중간 값 6, -5를 거쳐 -1이 남는다. `123++`는 `2+3 = 5`, `1+5 = 6`을 계산한다.
- 마지막 `return pop()`은 결과를 반환하고 `top`을 -1로 만든다.

# 괄호 안의 계산을 먼저 기록하기

- `1+(2+3)`에서는 괄호 안의 `2+3`을 먼저 계산해야 한다.
- 바깥의 `+`는 기다려야 한다. `(`를 스택에 넣어 두 연산의 경계를 표시한다.
- 안쪽 `+`를 넣을 때는 `(`의 우선순위 0이 더 낮으므로 `break`로 연산자 꺼내기를 멈춘다.
- `)`를 만나면 비어 있지 않은 동안 `op = pop()`으로 먼저 꺼낸다.
- 꺼낸 값이 `(`이면 출력에 쓰지 않고 `break`한다. 이미 스택에서 제거되었으므로 다시 pop하지 않는다.
- 그 밖의 연산자는 출력에 쓰고 반복한다. 괄호 자체는 출력에 쓰지 않는다.

# 괄호 변환 함수의 실제 흐름

- `eq_paren[8] = "1+(2+3)"`을 `infix_to_postfix_parentheses()`로 변환한다.
- 이 함수도 `top = -1`, `pos = 0`으로 시작한다. 입력의 `'\0'` 직전까지 읽는다.
- `3`까지 읽으면 출력은 `123`, 스택은 아래부터 `+`, `(`, `+`다. `top`은 2이고 데이터는 세 개다.
- `)`를 읽으면 안쪽 `+`를 출력에 쓰고 `(`를 꺼내 버린다. 출력은 `123+`다.
- 마지막에는 바깥 `+`를 꺼내 쓴다. 출력은 `123++`, `pos`는 5, `top`은 -1이다.
- 별도 대입문으로 `postfix[5]`에 `'\0'`을 쓴다. `pos`는 6이 된다.

# 현재 실습의 입력 조건

- 입력은 비어 있지 않은 올바른 수식이어야 한다. 입력 문자 최대 7개와 종료 문자가 8칸 배열 안에 들어가야 한다.
- 한 자리 숫자와 이항 연산자 `+`, `-`, `*`, `/`, `%`를 사용한다.
- `convert_to_postfix()`에는 괄호 없는 `eq`를 준다. `infix_to_postfix_parentheses()`에는 괄호가 올바르게 짝지어진 `eq_paren`을 준다.
- `7`, `1+2`처럼 짧은 식도 지원한다. 입력과 postfix 수식을 읽는 반복문은 종료 문자에서 멈춘다.
- 공백, 단항 부호, 여러 자리 피연산자는 제외한다. 0으로 나누지 않고 계산 결과는 C `int` 범위 안에 있어야 한다.
- 변환 함수는 빈 스택을 읽지 않도록 검사하지만 수식 문법을 검증하지 않는다. 짝 없는 `)`는 무시될 수 있고, 짝 없는 `(`는 출력에 남을 수 있다.
- 계산 함수는 필요한 피연산자가 있는지 확인하지 않는다. 입력 조건은 호출자가 지켜야 한다.
