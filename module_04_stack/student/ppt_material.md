# 쌓아놓는 형태의 자료구조

- 데이터를 저장해놓고 가장 최신 데이터만 읽거나 제거하는 방식이다.
- 데이터를 추가하거나 삭제할 때 기존 데이터들은 영향을 받지 않는다.

# 스택을 리스트로 구현하기

- 리스트에 데이터를 추가할 때 가장 끝에 추가한다.
- 리스트에서 데이터를 읽거나 삭제할 때 마지막 데이터만 읽거나 삭제한다.

# 데이터 추가하기

- 인덱스를 0부터 시작하므로, 데이터를 추가할 제일 끝 위치는 저장된 데이터의 개수와 같다.
- 해당 위치에 데이터를 저장하고 개수를 하나 증가시킨다.

# 데이터 삭제하기

- 인덱스를 0부터 시작하므로, 마지막 데이터의 위치는 저장된 데이터 개수에서 1을 뺀 것과 같다.
- 개수를 하나 감소시킨 뒤, 줄어든 개수를 인덱스로 사용해 마지막 데이터를 읽는다. (`stack[--size]`)

# 스택을 써서 수식 계산하기

- 1-2*3+4를 왼쪽부터 읽어나갈 때,
- 1을 보면 숫자 스택에 저장한다.
- -를 연산자 스택에 저장한다.
- 2를 숫자 스택에 저장한다.
- 다음 연산자 *가 우선순위가 더 높으므로, -를 그대로 보관한다.

# 스택을 써서 수식 계산하기

- *를 연산자 스택에 저장한다.
- 3을 숫자 스택에 저장한다.
- 다음 연산자 +가 우선순위가 더 낮으므로 스택에 있던 *을 먼저 계산해야 한다.

# 스택을 써서 수식 계산하기

- *를 연산자 스택에서 꺼낸다.
- 3을 숫자 스택에서 꺼낸다.
- 2를 숫자 스택에서 꺼낸다.
- 2*3을 계산해서 숫자 스택에 저장한다.
- 연산자 스택에 있는 -도, +와 우선순위가 같으므로 먼저 계산한다.

# 스택을 써서 수식 계산하기

- -를 연산자 스택에서 꺼낸다.
- 2*3을 숫자 스택에서 꺼낸다.
- 1을 숫자 스택에서 꺼낸다.
- 1-(2*3)을 계산해서 숫자 스택에 저장한다.
- 남은 연산자가 없으므로 +를 저장한다.

# 스택을 써서 수식 계산하기

- 4를 숫자 스택에 저장한다.
- 수식을 전부 읽었으므로 스택에 있는 연산자 +를 꺼낸다.
- 4를 숫자 스택에서 꺼낸다.
- 1-(2*3)을 숫자 스택에서 꺼낸다.
- 1-(2*3)+4를 스택에 저장한다. (최종)

# 수식을 계산하기 쉽게 다시 쓰기

- 숫자들은 그대로 있고, 연산자들의 위치만 계산할 타이밍에 맞게 조정해준다.
- 1 2 3 * - 4 +

# 다시 쓴 수식 계산하기

- 1을 스택에 추가한다.
- 2를 스택에 추가한다.
- 3을 스택에 추가한다.
- *을 보면 스택에서 3, 2를 뺀다.
- 2*3을 스택에 추가한다.

# 다시 쓴 수식 계산하기

- -를 보면 스택에서 (2*3), 1을 뺀다.
- 1 - (2*3)을 스택에 저장한다.
- 4를 스택에 저장한다.
- +를 보면 스택에서 4, (1-(2*3))를 뺀다.
- (1-(2*3))+4를 스택에 저장한다.
- 최종 계산 결과가 스택에 있다.

# 수식을 계산하기 쉽게 다시 쓰기

- 숫자는 그대로 쓴다.
- 연산자가 나오면 스택에서 우선순위가 높거나 같은 데이터를 다 빼서 쓰고, 연산자를 스택에 저장한다.
- 수식의 끝에 도달하면 스택에서 데이터를 다 빼서 쓴다.

# 현재 lab.c의 스택 표현

- `int stack[10]`과 전역 `size`를 두 단계에서 함께 사용한다.
- `push(int data)`는 `stack[size++] = data`로 저장 후 개수를 늘린다.
- `peek()`는 `stack[size - 1]`을 읽고, `pop()`은 `stack[--size]`로 개수를 줄인 뒤 읽는다.
- `is_full()`과 `is_empty()`는 상태만 알려준다. `push`, `peek`, `pop` 안에는 경계 검사가 없다.
- 가득 찼을 때 push하거나 비었을 때 peek/pop하면 배열 범위를 벗어난다. 호출 전에 조건을 확인한다.

# 변환 단계: 실제로 저장하는 센티널

- 입력은 `eq[8]`, 출력은 `eq_re[8]`이다. 현재 코드는 정확히 일곱 글자를 읽는다.
- `infix_to_postfix()`는 지역 출력 위치 `pos = 0`, 전역 `size = 0`으로 시작하고 `'\0'`을 push한다.
- `'\0'`의 우선순위는 0이다. 유효한 연산자보다 낮아서 연산자를 꺼내는 반복문이 빈 스택을 읽기 전에 멈춘다.
- 숫자는 `eq_re`에 쓰고, 우선순위가 높거나 같은 연산자를 먼저 꺼내 쓴다.
- 마지막에는 센티널까지 모두 꺼내 쓴다. `eq_re[7]`에 `'\0'`이 저장되고 `pos`는 8, `size`는 0이 된다.
- 출력 토큰은 일곱 개이며 종료 문자는 토큰에 포함하지 않는다.

# 계산 단계: 같은 정수 스택 재사용

- `eval_postfix()`는 전역 `size = 0`으로 초기화하고 같은 `int stack[10]`을 숫자와 중간 결과에 사용한다.
- 이번에는 센티널을 넣지 않는다. `eq_re[0]`부터 `eq_re[6]`까지만 읽는다.
- `push(c - '0')`로 문자 숫자를 정수로 바꿔 넣는다.
- 연산자를 만나면 오른쪽 피연산자 `num2`를 먼저 pop하고 왼쪽 `num1`을 pop한다.
- `calc(num1, num2, c)`의 결과를 다시 push한다. 중간 값 6, -5를 거쳐 -1이 남는다.
- 마지막 `return pop()`은 -1을 반환하고 `size`를 0으로 만든다.

# 현재 실습의 입력 조건

- 한 자리 숫자 네 개와 이항 연산자 세 개가 번갈아 나오는 정확히 일곱 글자를 사용한다.
- 연산자는 `+`, `-`, `*`, `/`, `%`이며 `eq[7]`은 `'\0'`이다.
- 더 짧은 식도 지원하지 않는다. 두 반복문은 항상 일곱 번 실행된다.
- 공백, 괄호, 단항 부호, 여러 자리 피연산자는 제외한다. 0으로 나누지 않고 계산 결과는 C `int` 범위 안에 있어야 한다.
- 이 조건은 호출자가 지키는 가정이다. 현재 소스가 잘못된 입력을 안전하게 거절하는 것은 아니다.
