# How to Store Data Smartly

## What is Data?

Data is simply anything a computer program works with—like names, numbers, text, images, and sounds.

## Why Does Data Need Structure?

If you only have one or two pieces of data, you can just drop them into the computer's memory and use them. But when you have dozens or thousands of items, it’s a completely different story. If data is scattered everywhere without any order, it becomes incredibly slow and inefficient to find or change the exact item you are looking for.

## What Does "Efficiency" Mean?

A computer's main resources are its brain (CPU) and its short-term memory (RAM). In programming, being "efficient" means saving effort (doing less work) and saving space (using less memory).

## How to Store Data

What kinds of data structures exist? The simplest way to organize data is to give each piece a number or a name tag.

Additionally, if different pieces of data are connected to each other, we can store the information about how they are related.

## How to Measure Efficiency

Running a program always takes a basic amount of work and memory space. Because of this, measuring efficiency doesn't mean much when you only have a tiny bit of data.

Usually, we measure efficiency by looking at what happens as the amount of data *grows*. We check patterns like:

* **Stays the same:** Does the work stay exactly the same, no matter how much data you add?
* **Grows steadily:** Do the work and memory increase at the same pace as the data?
* **Grows rapidly:** Do they increase much faster (like the square of the data amount) when the data grows?
