# 실제 초보자 교재 파일럿

이 파일럿은 학생을 평가하지 않아요. 교재가 초보자의 설명을 끊는 지점을 찾아요. PDF나 바꾼 사본을 만들지 않고 각 장의 `student/textbook.md`를 그대로 읽어요.

## 파일

- [학생 응답지](learner_response_template.md)는 읽기와 첫 답을 남겨요.
- [참여자용 선행 문제](participant_prerequisite_questions.md)와 [참여자용 바꾼 예](participant_transfer_questions.md)는 정답 없이 질문만 보여줘요.
- [진행자 기록지](facilitator_log_template.md)는 관찰, 판정, 수정, 재검사를 남겨요.
- [선행 확인 기준](prerequisite_probes.md)은 현재 장이 기대하는 앞 장 지식을 확인해요.
- [진행자 정답 기준](facilitator_answer_key.md)은 확인 문제와 바꾼 예의 최소 정답을 고정해요.
- [파일럿 현황](pilot_status.md)은 이름 없는 장별 결과만 모아요.

정답 기준은 학생에게 보여주지 않아요. 기존 `student/evidence_template.md`와 `student/rubric.md`도 쓰지 않아요. 그 문서들은 수업 뒤의 코드와 성취를 평가해요. 이 파일럿은 설명 전의 교재만 검사해요.

## 참여 조건

권장 인원은 네 명이고 3–5명까지 받아요. 각 장에는 선행 내용을 끝낸 유효 응답이 적어도 세 개 있어야 해요.

- 1장 시작 전에는 C의 변수, 함수, 배열, 반복문, 조건문만 안다고 두어요.
- 데이터 구조를 이미 정식으로 배운 사람의 응답은 보조 기록으로만 써요.
- 2장부터는 앞 장들의 누적 선행 관문을 모두 통과한 사람만 다음 장 판정에 넣어요.
- 같은 사람은 가능한 한 1장부터 16장까지 순서대로 따라가요.

참여는 자발적이어야 해요. 성적과 분리해요. 이름, 학번, 성적, 정확한 나이, 연락처를 파일럿 기록에 넣지 않아요. 임의의 `P01` 같은 코드만 써요. 소리나 영상을 기본으로 녹화하지 않아요. 기관의 동의와 자료 보관 규칙이 있으면 그 규칙을 먼저 따라요.

필기, 말하기, 그림, 촉각 자료, 화면 읽기 가운데 편한 응답 방식을 허용해요. 읽기 속도와 말솜씨는 판정하지 않아요.

## 시작 전에 고정해요

한 장을 읽는 동안 교재를 고치지 않아요. 기록지에 교재 버전이나 커밋을 적어요. 진행자는 다음 내용을 미리 정해요.

1. [선행 확인 기준](prerequisite_probes.md)에 적힌 현재 장의 짧은 문제
2. 이 장에서 말하기 설명을 맡을 두 참여자
3. 학생에게 보이지 않는 정답 기준
4. 이 장의 첫 응답 끝에 물을 바꾼 예 하나

참여자들은 다른 사람의 답이나 말하기 설명을 자기 응답이 끝나기 전에 듣지 않아요.

## 14주에 16장을 확인해요

| 주 | 읽는 순서 |
|---:|---|
| 1 | 1장 |
| 2 | 2장 |
| 3 | 3장 |
| 4 | 4장 |
| 5 | 5장 |
| 6 | 6장 |
| 7 | 7장 |
| 8 | 8장, 쉬고 9장 |
| 9 | 10장, 쉬고 11장 |
| 10 | 12장 |
| 11 | 13장 |
| 12 | 14장 |
| 13 | 15장 |
| 14 | 16장 |

한 장은 한 세션으로 나눠요. 25분이 지나면 쉬기를 제안해요. 한 세션은 60분을 넘기지 않아요. 8주와 9주의 두 세션 사이에는 반드시 쉬어요.

## 한 장을 진행해요

먼저 다음 문장을 그대로 읽어요.

> 이 활동은 학생이 아니라 교재를 확인해요. 모르면 모른다고 답하거나 건너뛸 수 있어요. 언제든 쉬거나 이유 없이 끝낼 수 있어요. 답은 성적에 쓰지 않아요.

1. 현재 장의 선행 확인 문제를 모두 물어요. 각 답에는 결과와 이유가 모두 필요하다고 먼저 알려요. 아직 설명하거나 고치지 않아요.
2. 참여자가 혼자 교재를 읽어요. 검색과 토론은 하지 않아요.
3. 같은 문장에 90초 머물면 계속 읽기, 표시하고 넘어가기, 쉬기, 끝내기 중 무엇을 원하는지 물어요. 시간만으로 막혔다고 판정하지 않아요.
4. 교재를 닫고 해결할 일, 기존 방법의 한계, 새 생각을 자기 말로 적어요.
5. 교재의 같은 예에서 현재 상태 다음의 한 단계를 예측하고 이유를 적어요.
6. 장 끝의 확인 문제를 적힌 그대로 물어요. 이어서 모든 문제에 같은 중립 질문 “그렇게 판단한 이유는 무엇인가요?”를 물어요. 결과와 이유를 함께 첫 답으로 고정해요.
7. 미리 정한 두 사람만 3–4분 동안 장을 말로 설명해요.
8. 마지막에 바꾼 예 하나를 풀어요.
9. 모든 첫 응답을 고정한 뒤에만 `H3`–`H5` 설명과 교정을 해요.

두 곳에서 계속 막히면 진행, 쉬기, 건너뛰기, 끝내기 중 무엇을 원하는지 물어요. 참여자가 원하거나 힘들어하면 바로 끝내요.

## 중립 질문만 써요

다음 질문은 답을 알려주지 않아요.

- “지금 무엇을 알아내려고 하나요?”
- “이 부분을 자기 말로 말해 주세요.”
- “다음 상태는 무엇일 것으로 보나요?”
- “그 판단의 근거가 있는 줄을 가리켜 주세요.”
- “읽는 흐름이 끊긴 곳이 있었나요? 없으면 없다고 말하고, 있었다면 첫 위치를 가리켜 주세요.”
- “계속하기, 쉬기, 건너뛰기, 끝내기 중 무엇을 원하나요?”

답을 넣은 질문은 쓰지 않아요. “이 용어가 어렵죠?”나 “큐라서 먼저 나오는 거죠?”처럼 묻지 않아요. 첫 응답을 고정하기 전에는 맞았다는 표정, 칭찬, 고침, 새 예도 주지 않아요.

## 도움 수준을 기록해요

| 표시 | 실제로 한 일 |
|---|---|
| `H0` | 도움 없이 진행했어요 |
| `H1` | 같은 지시를 되풀이하거나 화면 위치만 알려줬어요 |
| `H2` | 위의 중립 질문만 했어요 |
| `H3` | 새 사실 없이 같은 뜻으로 문장을 바꿔 말했어요 |
| `H4` | 앞 장의 내용을 다시 가르쳤어요 |
| `H5` | 현재 장의 내용이나 답을 가르쳤어요 |

첫 읽기, 확인 문제, 말하기 설명이 모두 잠길 때까지 `H0`–`H2`만 써요. `H3`–`H5`는 그 뒤의 원인 진단과 수업에만 써요. `H3` 이상 뒤의 답은 독립 정답 수에 넣지 않아요. `H3` 뒤에 바로 이해했다면 원문 표현 문제의 근거가 될 수 있어요. `H5`가 나오면 첫 이해 측정은 끝나요.

## 원인을 나눠요

- **문장 문제**: 선행 확인은 모두 통과했지만 정확한 원문에서 막혀요. 같은 뜻의 쉬운 표현 뒤에는 이해해요.
- **선행 문제**: 편집 기준상 앞 장 내용이고 연결된 선행 확인도 실패해요. 현재 문장을 바꿔 말해도 해결되지 않아요.
- **현재 설명 문제**: 선행 내용은 알지만 새 생각의 이유나 진행을 본문만으로 만들 수 없어요.
- **사실 문제**: 코드 계약, 수치, 표, 그림, 설명이 서로 맞지 않아요.
- **진행 조건**: 피로, 화면 문제, 지시 실수, 힌트 노출이 결과에 섞였어요.
- **판정 보류**: 근거가 한쪽으로 모이지 않아요.

이 장에서 새로 배우는 내용은 선행 문제로 돌리지 않아요. 두 명 이상이 앞 장의 같은 내용을 잊었다면 앞 장이나 두 장 사이의 연결을 다시 확인해요.

## 누적 선행 관문을 지켜요

참여자는 한 장의 필수 확인 문제 중 75% 이상에서 `2`를 받고 바꾼 예에서도 `2`를 받아야 그 장의 관문을 통과해요. `2`는 결과와 이유가 모두 맞고 `H0`–`H2`만 받은 첫 답이에요.

관문을 통과하지 못하면 첫 증거를 모두 잠근 뒤 고정된 설명과 값만 바꾼 재문제를 줘요. 재문제를 통과하기 전의 뒤 장 응답은 보조 기록으로만 써요. 앞 장이 수정 중이면 뒤 장 자료를 모을 수는 있지만 앞 장 재검사가 끝날 때까지 뒤 장을 파일럿 통과로 정하지 않아요.

## 통과와 수정을 정해요

3–5명의 결과는 작은 파일럿이에요. 전체 학생에게 그대로 일반화하지 않아요.

`2`만 정답으로 세어요. `1`은 일부 정답이고, `0`과 `S`는 정답 근거가 없어요. 필요한 `2`의 수는 다음과 같아요.

| 유효 참여자 수 | 각 항목에 필요한 `2` |
|---:|---:|
| 3 | 3 |
| 4 | 3 |
| 5 | 4 |

한 장은 다음 조건을 모두 만족할 때 **파일럿 통과**예요.

- 선행 조건을 만족한 응답이 세 개 이상 있어요.
- 사실 문제와 앞에서 배우지 않은 용어가 없어요.
- 문제, 기존 방법의 한계, 새 생각, 정식 이름, 예의 다음 상태가 각각 위 표의 수만큼 `2`예요.
- 각 필수 확인 문제와 바꾼 예가 각각 위 표의 수만큼 `2`예요.
- 두 말하기 담당자가 모두 세 말하기 기준을 `H0`–`H2`로 설명하고 핵심 규칙을 반대로 말하지 않아요.
- 같은 문장이나 인과관계에서 두 명이 막히지 않아요.

다음 경우에는 고쳐요.

- 사실 문제나 뒤 장 지식 의존이 한 번이라도 확인돼요.
- 한 사람의 막힘이 같은 사람의 틀린 설명이나 확인 문제에서 다시 보여요.
- 두 명이 같은 문장, 같은 진행, 같은 잘못된 인과에서 막혀요.
- 필수 문제 하나라도 위의 통과 수에 못 미쳐요.

원인이 된 가장 작은 문장이나 연결만 고쳐요. 순서나 같은 예 전체가 문제라면 그 범위만 넓혀요. 문장 수정은 이전 해설과 정답을 보지 않은 새 참여자 두 명에게 확인해요. 원래 막힌 사람의 반응은 보조 기록으로만 써요. 개념 순서나 대표 예를 바꾸면 새 참여자 세 명 이상에게 장 전체를 다시 확인해요.

## 결과를 남겨요

개별 원자료는 성적 담당자에게 보여주지 않아요. 저장소에는 이름 없는 합계, 문제 위치, 수정 근거, 재검사 결과만 남겨요. 기관 규정이 없으면 개인 응답은 세션 뒤 30일 안에 이름 없는 합계로 옮기고 안전하게 폐기해요.

16장이 모두 파일럿 통과하면 [교재 검증 기록](../KOREAN_TEXTBOOK_VALIDATION.md)에 참여 인원 범위, 교재 버전, 통과·수정 장, 재검사 결과만 더해요.
