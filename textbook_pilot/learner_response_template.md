# 교재 읽기 응답지

이 응답지는 학생을 채점하지 않아요. 교재에서 막히는 곳을 찾아요. 이름과 학번을 쓰지 않아요.

```text
참여 코드:
장:
교재 버전:
완료하고 관문을 통과한 마지막 장: 0–15
현재 주제를 배운 적: 없음 / 이름만 들음 / 배운 적 있음
응답 방식: 글 / 말 / 그림 / 촉각 자료 / 화면 읽기
읽은 시간(분):
```

## 읽다가 멈춘 곳

없으면 “없음”이라고 써요. 정확한 줄 번호 대신 제목과 문장의 첫 몇 단어를 적어도 돼요.

| 제목과 첫 몇 단어 | 무슨 일이 있었나요 | 지금은 무슨 뜻이라고 보나요 |
|---|---|---|
| | 모르는 말 / 원인 연결 끊김 / 다음 상태를 못 정함 / 앞과 모순 / 코드·표가 다름 / 기타 | |
| | | |
| | | |

## 자기 말로 설명해요

1. 이 장이 해결하려는 일은 무엇인가요?

   답:

2. 앞에서 쓰던 방법은 어디에서 막히나요?

   답:

3. 이 장의 새 생각을 정식 이름 없이 한 문장으로 말해 주세요.

   답:

4. 그 생각의 정식 이름은 무엇인가요?

   답:

## 같은 예의 다음 상태를 정해요

```text
진행자가 고른 현재 상태:
내가 예상한 다음 상태:
그렇게 판단한 이유:
본문에서 근거가 된 제목이나 문장:
```

## 확인 문제에 답해요

교재를 닫은 첫 답을 적어요. 각 답에는 결과와 그렇게 판단한 이유를 함께 적어요. 모르면 “모름”, 원하지 않으면 “건너뜀”이라고 써요.

| 문제 번호 | 첫 답 | 판단 이유 | 근거가 있던 제목이나 문장 |
|---:|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |
| 4 | | | |
| 5 또는 없음 | | | |

## 바꾼 예

```text
문제:
첫 답:
이유:
```

## 끝에 남은 것

```text
가장 먼저 막힌 문장이나 말(없으면 없음):
아직 설명할 수 없는 것(없으면 없음):
쉬기 / 계속하기 / 건너뛰기 / 끝내기 중 고른 것:
```
