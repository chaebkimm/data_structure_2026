# 참여자용 선행 확인 문제

진행자가 지정한 절만 사용해요. `N장 전`은 해당 장을 열기 전에 묻고, `학습 중`은 적힌 부분을 읽은 뒤에만 물어요. 아직 배우지 않은 현재 장 개념을 진입 조건으로 쓰지 않아요.

모든 답에는 결과와 이유가 필요해요. 정답 기준은 이 파일에 없어요.

## 1장 전

1. int values[4] = {3,5,7,9};에서 읽을 수 있는 인덱스와 값의 수는 무엇인가요?
2. for (i=0; i<4; i++)의 몸체는 몇 번 실행되고, 마지막 몸체 실행에서 i는 얼마인가요?

## 2장 전

1. size=3, capacity=5인 고정 배열 리스트에서 현재 값의 인덱스는 어디까지인가요?
2. 배열 인덱스와 그 칸에 저장된 값은 무엇이 다른가요?
3. 고정 배열이 가득 찼을 때 거부한 삽입은 기존 값과 size, 용량을 어떻게 바꾸나요?

## 3장 전

1. nodes 배열에서 물리적으로 붙어 있는 두 칸이 자동으로 부모와 자식이 아닌 이유는 무엇인가요?
2. 이진 트리에서 순환이나 한 자식의 두 부모를 허용하면 왜 안 되나요?

## 4장 전

1. int values[5]에서 size=3이면 현재 값의 위치와 다음 삽입 위치는 어디인가요?
2. 작업량이 O(1)인 경우와 O(n)인 선형 탐색의 최악 경우는 입력 수에 따라 어떻게 달라지나요?

## 5장 전

1. 이진 트리의 root, 왼쪽·오른쪽 자식, leaf는 무엇인가요?
2. 스택에 A,B,C를 차례로 넣으면 어떤 순서로 꺼내나요?

## 6장 전

1. 무방향 간선은 adjacency list의 어느 정점에 저장하나요?
2. 같은 DFS에서 visit_num, parent, back_num은 무엇을 기록하나요?
3. postorder 작업은 자식 호출과 비교해 언제 실행하나요? 스택은 어느 항목을 먼저 꺼내나요?

## 7장 전

1. 배열 리스트 중간에 값을 넣으면 뒤의 활성 값은 어떻게 되나요?
2. 배열의 물리적 칸 순서와 트리의 논리적 연결 순서는 어떻게 다를 수 있나요?

## 8장 전

1. 별도의 새 실행에서 new_lnode()를 처음 부르면 어느 칸을 얻나요? 이후 init_lnodes_pool()를 다시 부르면 사용 중인 풀은 어떻게 되나요?
2. simple_delink_next_lnode_from_prev(prev)가 돌려준 노드와 free_lnode의 역할은 무엇이 다른가요?
3. 7장의 큐에서 17,23,31을 넣은 노드들을 차례로 꺼낼 때 어떤 값부터 읽나요? dequeue_lnode() 자체의 반환값과 마지막 두 끝을 말해요.
4. 트리 노드의 깊이는 무엇이며, 그래프에서 이미 발견한 정점을 기록해야 하는 이유는 무엇인가요?

## 8장 학습 중 — 배열 큐·값 어댑터를 읽은 뒤

1. 선형 큐와 원형 큐의 front, rear는 무엇이며 25칸 원형 큐의 활성 용량은 얼마인가요?
2. 8장의 dequeue()와 7장의 dequeue_lnode()는 무엇을 반환하고 누가 큐 칸을 재활용하나요?

## 8장 학습 중 — 트리 BFS를 읽은 뒤

1. 원래 F root 트리에서 F 처리 뒤와 이어 A 처리 뒤 대기 순서는 무엇인가요?
2. 한 부모만 갖는 트리와 달리 그래프에서 같은 정점을 여러 번 만날 수 있는 이유는 무엇인가요?

## 9장 전

1. lnodes[node].next가 -1이면 무엇을 뜻하고, 다음 노드로 이동할 때 어느 값을 인덱스로 쓰나요?
2. new_lnode()는 인수를 받나요? 반환값 -1과 성공한 칸의 data/next는 어떻게 다루나요?
3. init_lnodes_pool()를 두 번째 부르면 활성 노드나 저장 데이터가 초기화되나요?

## 10장 전

1. FIFO 큐와 LIFO 스택은 다음에 꺼낼 값을 각각 어떻게 정하나요?
2. 노드 풀이 모두 사용 중일 때 save_data(hash,data)의 반환값과 기존 상태는 무엇인가요?
3. 배열의 예약 용량과 활성 원소 수는 무엇이 다른가요?

## 11장 전

1. 그래프 adjacency list와 정점 인덱스는 각각 무엇을 저장하고 가리키나요?
2. BFS에서 목표의 이전 칸들을 따라 경로 하나를 복원하려면 어떻게 하나요?
3. 최소 힙의 다음 항목은 어디 있으며, ID 힙의 역위치 표는 swap 때 어떻게 바뀌나요?

## 12장 전

1. nodes[i].left/right에는 문자 키와 자식 인덱스 중 무엇을 저장하나요? 없는 자식의 표시는 무엇인가요?
2. leaf의 높이와 root에서 가장 먼 leaf까지 간선이 세 개인 트리의 높이는 얼마인가요?

## 13장 전

1. 활성 길이가 n인 배열에서 읽을 수 있는 인덱스 범위는 무엇인가요?
2. 최소 힙의 부모·자식 규칙이 배열 전체를 작은 순서로 정렬하나요?
3. 해시 테이블의 정확한 키 찾기와 AVL의 키 순서에는 어떤 차이가 있나요?

## 14장 전

1. 간선을 비용순으로 정렬하면 무엇을 알 수 있고, 두 끝점이 이미 연결됐는지도 알 수 있나요?
2. 무방향 그래프의 연결 요소와 순환은 무엇인가요?
3. 데이크스트라의 인덱스 힙에서 기다리는 정점의 더 작은 비용을 찾으면 어떻게 하나요?

## 14장 학습 중 — DSU를 읽은 뒤, Kruskal을 읽기 전

1. DSU에서 find로 얻은 대표가 같은 두 끝점 사이에 새 간선을 더하면 어떻게 되나요?
2. union by size와 경로 압축은 각각 무엇을 바꾸고 무엇을 유지하나요?
