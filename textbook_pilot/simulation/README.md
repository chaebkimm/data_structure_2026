# 합성 초보자 파일럿

이 폴더는 실제 사람이 아닌 세 초보자 역할의 모의 응답을 기록해요. 교재 버전 이름은 `2026-08-11-sim-1`이에요.

수정된 질문으로 1장부터 16장까지 다시 읽은 최신 결과는 [완전 순차 합성 파일럿 2차](round2/aggregate.md)에 있어요.

[종합 결과](aggregate.md)는 원응답, 엄격 채점, 고친 질문 방식의 짧은 재검사를 함께 정리해요.

| 코드 | 시작 조건 | 일부러 주지 않은 지식 |
|---|---|---|
| P01 | 기본 C가 강하고 그림으로 차분히 따라가요 | 자료구조, 포인터·구조체 숙련 |
| P02 | 기본 C가 보통이고 말로 이해해요 | 자료구조, 포인터 숙련 |
| P03 | 배열 위치 계산과 코드 추적이 강해요 | 자료구조, 기술 용어 숙련 |

세 역할은 1장부터 16장까지 순서대로 읽어요. 정답 기준, 코드 헤더, 시험, 다른 참여자의 답은 먼저 보지 않아요. 장마다 선행 문제, 본문, 확인 문제, 바꾼 예 순서로 답해요.

합성 결과는 다음 일만 할 수 있어요.

- 실제 학생에게 주기 전에 모호한 문장과 판정 양식을 한 번 더 점검해요.
- 같은 오답이 여러 역할에서 나오는지 찾아요.
- 수정 뒤 같은 질문을 다시 돌릴 후보를 정해요.

합성 결과는 실제 읽기 시간, 긴장, 피로, 접근성, 교실 상호작용을 재현하지 못해요. [실제 파일럿 현황](../pilot_status.md)을 통과로 바꾸는 근거로 쓰지 않아요.
