# 합성 초보자 파일럿 종합

> **합성 자료:** 사람에게서 받은 결과가 아니에요. 실제 파일럿 통과 근거나 학생 성취 자료로 쓰지 않아요.

> 이 문서는 첫 합성 실행 기록이에요. 수정된 질문으로 1장부터 16장까지 다시 읽은 [2차 종합](round2/aggregate.md)이 최신 결과예요.

## 결론

세 초보자 역할이 1장부터 16장까지 순서대로 읽었어요. 48개 장 세션, 확인 문제 213개, 바꾼 예 48개, 구두 설명 32개를 만들었어요.

- 본문·표·코드가 서로 다른 사실 문제는 없었어요.
- 두 역할 이상이 읽은 뒤에도 유지한 같은 오개념은 없었어요.
- 확인 문제 213개에는 완전히 틀린 답이 없었어요.
- 교재 본문은 고치지 않았어요.
- 실제 파일럿 현황은 16장 모두 `미실시`로 남겨요.

## 엄격 점수는 이렇게 읽어요

원래 합성 버전 `2026-08-11-sim-1`의 참여자용 질문은 모든 답에 이유가 필요하다고 분명히 쓰지 않았어요. 세 역할은 정답 상태만 자주 적었어요. 진행자 기준은 이유가 빠진 답을 `1`로 채점했어요.

| 항목 | `2`: 결과와 이유 | `1`: 일부 또는 이유 없음 | `0`: 틀림·모름 |
|---|---:|---:|---:|
| 해결할 일·기존 한계·쉬운 새 생각·정식 이름 | 192 | 0 | 0 |
| 같은 예의 다음 상태 | 21 | 27 | 0 |
| 확인 문제 | 200 | 13 | 0 |
| 바꾼 예 | 14 | 34 | 0 |

1장 선행 답부터 이유가 빠졌기 때문에 누적 관문으로는 세 역할 모두 1–16장 전체가 보조 기록이에요. 이것은 교재 실패 수치가 아니에요. 질문과 채점 조건이 맞지 않은 결과예요.

일부 엄격 채점은 질문이 요구하지 않은 값까지 답에 기대했어요. 5장 1번, 7장 1번, 8장 2번, 11장 3번이 대표적이에요. 따라서 세 채점 문서는 원자료 감사 기록으로만 두고 장 통과표로 합치지 않아요.

## 확인된 수정

교재가 아니라 응답 지시를 고쳤어요.

- 선행 문제와 바꾼 예에 결과와 이유를 함께 답하라고 썼어요.
- 확인 문제 응답표에 판단 이유 칸을 따로 뒀어요.
- 진행자가 모든 확인 문제 뒤에 같은 중립 질문 “그렇게 판단한 이유는 무엇인가요?”를 묻게 했어요.
- 진행자 선행 기록 칸을 `첫 결과와 이유`로 바꿨어요.

새 역할 두 명이 고친 지시만 보고 1, 3, 5, 7, 9, 12, 14, 16장을 다시 답했어요. 선행·확인·바꾼 예 36개 모두 결과와 이유를 나눠 적었어요. 이 재검사는 질문 방식만 확인해요. 교재 통과를 뜻하지 않아요.
