# P01 합성 기록 엄격 채점

> **합성 자료:** 이 문서는 실제 참여자 결과가 아니다. `P01.md`의 합성 응답을 `2026-08-11-sim-1` 기준으로 채점한 진행자용 검토이며, 실제 파일럿 통과 인원이나 `pilot_status.md`의 근거로 쓰면 안 된다.

## 채점 규칙

- 별도 도움 기록이 없는 첫 응답은 지시대로 모두 `H0`로 보았다.
- `2`는 답과 그 답을 지지하는 이유 또는 계산·상태 전환이 응답 안에 명시된 경우만 주었다. 맞는 결과만 있고 이유가 없으면 `1`이다. 쓰이지 않은 이유는 정답 기준에서 보충하지 않았다.
- 핵심 벡터 순서는 `[문제, 이전 방법의 한계, 쉬운 말의 새 생각, 정식 이름, 같은 예의 다음 상태]`이다.
- 확인 벡터는 교재에 인쇄된 문제 순서다. 5장 5번은 선택 문제라 `2*`로 표시하고 75% 관문 분모에서는 뺐다.
- 구두 벡터 순서는 `[문제·한계, 새 생각·정식 이름, 대표 예 상태 변화]`이다. `독`은 `H0` 독립 설명, `—`는 이 참여자의 지정 장이 아님을 뜻한다.
- 선행의 `로컬`은 해당 장 직전 문제만, `누적`은 앞 장 관문과 재검사까지 포함한다.

## `1` 판정의 근거

- 선행: 1장 P1·P2, 2장 P2, 5장 P2, 8장 P2, 9장 P3, 15장 P2는 결과만 있고 규칙이나 계산 이유가 없다. 14장 P3의 “허용 범위 안인지”는 기준인 `0 <= id < 활성 원소 수`를 명시하지 않아 정확한 범위를 판정할 수 없다.
- 핵심 다음 상태: 1, 3, 5, 6, 7, 8, 9, 13, 15장은 맞는 다음 상태를 적었지만 왜 그 상태가 되는지 규칙·식·인과를 응답에 남기지 않았다. 2, 4, 10, 11, 12, 14, 16장은 각각 포인터 연결, match/pop, 도착 순번, swap, 비용 비교, 안전한 재연결, 같은 DSU 묶음/순환이라는 전환 근거가 명시돼 `2`다.
- 확인 문제: 1장 Q1은 `0..2`만 적고 용량의 3..7이 목록 값이 아닌 이유를 남기지 않았다. 12장 Q3은 보존되는 값만 적고 “같으면 완화하지 않는다”는 판단 근거를 남기지 않았다. 나머지는 질문이 요구한 인과 또는 정답 기준의 상태 전환을 명시했다.
- 전이: 2장(왼쪽 부분 트리의 70이 60보다 큼), 4장(두 번째 열림이 한도를 넘음), 13장(삭제 흔적을 지나 기존 21을 찾음), 14장(동률의 작은 뿌리와 실제 find 경로)만 결과와 이유가 모두 있다. 나머지는 결과가 맞더라도 전체 결과를 정당화하는 규칙이나 추적이 없어서 `1`이다.
- 구두 설명이 있는 1, 3, 4, 6, 7, 9, 10, 12, 13, 15, 16장은 세 기준 모두 독립 설명으로 판정했다. 응답에 반대 규칙이나 도움 흔적이 없다.

## 선행 관문과 포함 범위

1장 선행 문제 두 개에 이유가 기록되지 않아 엄격 기준에서는 1장부터 선행을 통과하지 못한다. 또한 1장 확인 문제는 `2`가 3/4로 75%이지만 전이가 `1`이므로 1장 자체 관문도 통과하지 못한다. 고정 설명 뒤 재문제나 재검사 기록이 없으므로 2–16장은 모두 누적 선행 관문 미통과 상태의 **보조 기록**이다. 각 장의 로컬 점수는 원자료 진단을 위해 표에 그대로 보존했다.

## 의심되는 교재·파일럿 문제

1. **prerequisite — 14장 외부 ID 범위 연결:** “허용 범위”라는 답만 나와 `0 <= id < 활성 원소 수`를 회상했는지 알 수 없다. 13장 또는 13→14장 연결에서 정확한 경계를 다시 확인할 후보지만, 먼저 같은 선행 문제의 독립 재응답이 필요하다.
2. **uncertain — 상태 예측의 인과가 기록되지 않음:** 1, 3, 5–9, 13, 15장의 다음 상태가 맞아도 이유 칸의 증거가 없다. 교재의 현재 설명 부족인지, 합성 기록이 응답지의 “이유/본문 근거” 칸을 압축하며 빠뜨린 것인지 이 자료만으로 구별할 수 없다.
3. **uncertain — 전이 이유가 광범위하게 빠짐:** 1, 3, 5–12, 15, 16장의 전이가 정답 결과 중심이다. 여러 장에서 같은 기록 형태로 나타나므로 곧바로 각 교재의 결함으로 세지 말고, 이유를 별도 칸에 보존한 새 시뮬레이션/실제 파일럿으로 확인해야 한다.
4. **uncertain — 보고된 읽기 막힘:** 모든 장의 “막힌 지점”은 나중의 확인 답 또는 구두 설명에서 대체로 회복됐지만, 정확한 원문 첫 구절과 잠근 뒤 `H3`–`H5` 진단이 없다. 따라서 **text**나 **current-explanation**으로 확정하지 않았다.
5. **fact/session/text:** 본문·표·코드의 충돌, 피로·화면·힌트 노출, 또는 같은 뜻의 쉬운 표현 뒤에만 해결됐다는 증거는 없다. 이 세 분류의 확인된 문제는 0건이다.

## 결론

엄격한 단일 참여자 기준에서 실패 장은 **1–16장 전부**다. 다만 원응답의 내용만 보면 2장과 4장은 핵심·확인·전이(및 지정된 4장 구두 설명)를 모두 충족한다. 14장도 현재 장 내용은 모두 충족하지만 로컬 선행 P3 때문에 포함할 수 없다. 이 구분은 합성 기록의 유용한 내용과 파일럿 포함 자격을 섞지 않기 위한 것이다.
