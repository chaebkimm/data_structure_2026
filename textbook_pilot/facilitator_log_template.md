# 교재 파일럿 진행자 기록지

학생의 능력이 아니라 교재의 근거를 기록해요. 보이는 행동과 원인 판정을 나눠 써요.

## 세션

```text
세션 코드:
참여 코드:
장:
교재 버전 또는 커밋:
C 기초 확인: 예 / 아니요
완료한 마지막 장: 0–15
구조체 경험: 없음 / 본 적 있음 / 사용해 봄
포인터 경험: 없음 / 본 적 있음 / 사용해 봄
현재 주제 경험: 없음 / 이름만 들음 / 배운 적 있음
응답 방식:
걸린 시간(30초 단위):
```

직접 이름, 학번, 성적, 연락처, 정확한 나이와 시간은 적지 않아요.

관찰에는 “세 번 다시 읽음”처럼 보인 일을 써요. “포인터를 못함” 같은 해석은 원인 후보에 써요.

## 첫 응답 판정

`2`는 결과와 이유가 모두 본문 근거와 맞아요. `1`은 일부만 맞거나 이유가 빠져요. `0`은 틀리거나 모름이에요. `S`는 참여자가 건너뛰었어요. 통과 판정에는 `H0`–`H2`의 `2`만 세어요. `H3` 이상 뒤의 답에는 `T`를 붙여 첫 이해 합계에서 빼요.

## 세션 원인 판정

멈춤 하나만 보고 판정하지 않아요.

```text
정확한 문제 위치:
선행 확인 결과:
같은 뜻의 쉬운 표현 뒤 결과:
현재 장의 새 사실을 가르쳐야 했나요:
본문만으로 답할 수 있었나요:
본문·표·코드가 같은 상태였나요:
최종 분류: 문장 / 선행 / 현재 설명 / 사실 / 진행 조건 / 보류

```
