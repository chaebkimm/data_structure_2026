This activity reuses tree words from Module 2. A **tree** is a hierarchy of
connected items. Its one starting item is the **root**. Each stored item is a
**node**. A node directly below another is a **child**. A **link** connects a
parent to a child.

The example is synthetic, meaning invented for safe practice. A **check
marker** is a stored note saying an item needs attention. It does not make a
claim about a real system.
