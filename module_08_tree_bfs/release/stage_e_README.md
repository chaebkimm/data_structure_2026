# Module 8 — Stage E: Lab and Evidence

Start with `student/lab.md`, then edit only:

- the three numbered `TODO` sections in `code/starter/tree_bfs.c`; and
- the three `TODO` test sections in `code/tests/test_student.c`.

`TODO` marks an unfinished section that the student must complete.

The tree constructor, strict-BST insertion helper, cleanup helper, and typed
node/depth Queue are supplied. Students implement level-order traversal,
shallowest-value search, and BFS edge-height calculation. The autopsy—a
careful investigation after a failure—is standalone and stays within fixed
array bounds.

Submit the files and evidence listed in the lab, then complete
`student/evidence_template.md`.
