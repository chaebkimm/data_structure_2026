# Stage A — Initial Inquiry: Linear Format

The root is `*`. Its left child is `+`; its right child is `2`. The `+` node
has left child `3` and right child `5`. The digits have no children.

1. Write an order for creating a complete independent copy.
2. Write an order that places each operator between its operands.
3. State where parentheses are needed in the printed expression.
4. Write the order in which values become available during calculation.
5. While processing `3`, list the unfinished work that must be remembered.
6. State the rule for a `NULL` child.
