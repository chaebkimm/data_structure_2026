# Module 5 Vocabulary

- **Tree traversal:** a planned visit to every node in a valid tree.
- **Depth-first search (DFS):** finishing one branch before returning to another.
- **Recursion:** a function solving a smaller version of its own task.
- **Base case:** an input that returns without another recursive call.
- **Preorder:** current node, left subtree, right subtree.
- **Inorder:** left subtree, current node, right subtree.
- **Postorder:** left subtree, right subtree, current node.
- **Expression tree:** leaves store operands and internal nodes store operators.
- **Node pool:** a fixed array that supplies node addresses.
- **Tree height (`h`):** the longest downward path that controls call-stack use.
