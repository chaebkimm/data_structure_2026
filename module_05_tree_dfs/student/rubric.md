# Module 5 Rubric

This rubric assesses the current array-based [`lab.c`](lab.c) sequence.

| Area | Points |
|---|---:|
| Recursive DFS hook orders and negative-index base case explained | 20 |
| Stack DFS trace includes progress, absent children, and reset precondition | 25 |
| Postfix construction records indices, right-before-left pops, and final root | 20 |
| Infix output preserves grouping, terminates, and restarts its cursor | 20 |
| Three justified student cases with reproducible results | 10 |
| Capacity assumptions and time/space explanation | 5 |
| Total | 100 |

Do not award implemented validation or safe failure handling to functions
that contain no such checks. Reconstruction and the pointer-based
copy/print/evaluation scaffold are optional assignments with separate
contracts; assess them separately when assigned.
