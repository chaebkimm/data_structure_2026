# Stage B — Five-Minute Cognitive Pause

Use the tree for `(3+5)*2`.

1. Write its preorder, inorder, and postorder symbol sequences.
2. Match preorder to copying, inorder to printing, and postorder to evaluation.
3. Explain why the `+` subtree needs parentheses when printed below `*`.
4. List the active non-`NULL` calls while the current node is `3`.
5. State the time cost for `n` nodes and call-space cost for height `h`.
