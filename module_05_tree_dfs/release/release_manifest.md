# Module 5 Release Manifest

Run `prepare_student_release.ps1` to create five staged archives.

1. Stage A: inquiry prompts.
2. Stage B: representation reveal, pause, and vocabulary.
3. Stage C: investigation worksheets.
4. Stage D: textbook and diagrams.
5. Stage E: lab, evidence files, starter code, public tests, and autopsy.

Before release, run `make solution-core solution-extension` in `code/` and
confirm the archives contain no instructor answer or solution source.
