# Module 5 — Stage E: Lab and Evidence

Start with `student/lab.md`, then edit only:

- `code/starter/tree_dfs.c`;
- `code/tests/test_student.c`.

The supplied support files provide node construction, strict binary search
tree (BST) insertion, and a Stack designed specifically for tree-node
addresses. Strict BST ordering places every lower key to the left and every
higher key to the right. The autopsy—a careful investigation after a
failure—contains an intentional traversal-order defect and remains separate
from passing tests.

Submit the files and evidence listed in the lab, then complete
`student/evidence_template.md`.
