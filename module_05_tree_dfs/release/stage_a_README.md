# Stage A — Initial Inquiry

Follow child indices, choose when to record symbols, and predict how saved
progress resumes unfinished work. Then build an expression tree from postfix
and investigate parentheses in its infix output. Preserve first predictions
before Stage B reveals the formal traversal names and implementation model.

Links in the prompts name files from the original `student/` directory.
The slides and textbooks arrive in Stage D; `lab.c` arrives as
`student/lab.c` in Stage E. Use the prompt's supplied diagram for first
predictions, then open those later files when their stage is released.
