# Linked queue example and Module 8 reuse

The [Week 7 linked-list page](week_07_linked_list.md) includes a linked FIFO
queue as an application of list endpoints and node recycling. Its public
`enqueue(value)` reports allocation success; `dequeue()` returns a value
and automatically recycles its node.
[Week 8](week_08_bfs.md) reuses that implementation for tree and graph BFS
and compares linear/circular array queues.

This compatibility entry adds no separate vocabulary count, question set,
or submission.
