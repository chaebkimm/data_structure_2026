# Linked queue example and Module 8 transfer

The [Week 7 linked-list page](week_07_linked_list.md) includes a linked FIFO
queue as an application of list endpoints and node recycling. Its node
operations exchange indices; the caller writes data before enqueue and
reads and recycles a removed node.
[Week 8](week_08_bfs.md) transfers the FIFO rule to linear/circular array
comparisons and tree levels, then stores whole coordinates in a linear
array queue for maze BFS.

This compatibility entry adds no separate vocabulary count, question set,
or submission.
