# 2025 기출문제 및 답안 (중간고사 범위)

## 리스트

### 리스트가 무엇인지 설명하시오

리스트는 데이터를 순서대로 저장하는 자료구조다. 각 데이터는 위치를 가지며, 같은 값이 여러 번 들어갈 수 있다. 특정 위치의 데이터를 조회하거나, 원하는 위치에 데이터를 추가하고 삭제할 수 있다. 배열로 구현할 수 있다.

### 리스트를 배열로 구현할 때 어떤 정보를 저장하고, 어떻게 데이터를 추가하고 삭제하는지 설명하시오

데이터를 저장할 배열, 현재 저장된 데이터의 개수인 크기(size), 배열에 저장할 수 있는 최대 개수인 용량(capacity)을 저장한다. 데이터는 배열의 `0`번부터 `size - 1`번까지 연속해서 저장한다.

- 추가: 위치 `i`에 데이터를 넣으려면, 기존의 `i`번부터 마지막 데이터까지 뒤에서부터 한 칸씩 오른쪽으로 이동한다. `array[i]`에 새 데이터를 저장하고 `size`를 1 증가시킨다. 배열이 가득 차 있다면 더 큰 배열을 만들고 기존 데이터를 복사한다.
- 삭제: 위치 `i`의 데이터를 삭제하려면, `i + 1`번부터 마지막 데이터까지 한 칸씩 왼쪽으로 이동하여 빈자리를 채운다. 이후 `size`를 1 감소시킨다.

임의 위치의 추가와 삭제는 최대 `n`개의 데이터를 이동해야 하므로 O(n)이고, 인덱스를 이용한 조회는 O(1)이다.

## 스택

### 스택이 무엇인지 설명하시오

스택은 가장 나중에 넣은 데이터를 가장 먼저 꺼내는 LIFO(Last In, First Out) 자료구조이다. 데이터의 추가와 삭제는 모두 맨 위인 `top`에서 이루어진다. 데이터를 넣는 연산을 `push`, 꺼내는 연산을 `pop`, 꺼내지 않고 맨 위 데이터를 확인하는 연산을 `peek`이라고 한다.

### 스택을 배열로 구현할 때 어떤 정보를 저장하고, 어떻게 데이터를 추가하고 삭제하는지 설명하시오

데이터를 담는 배열, 배열의 용량(capacity), 맨 위 데이터의 인덱스인 top을 저장한다. 빈 스택의 `top`은 `-1`로 둔다.

- 추가(push): 배열이 가득 찼는지 확인한다. 공간이 있다면 `top`을 1 증가시키고 `array[top]`에 새 데이터를 저장한다.
- 삭제(pop): `top == -1`이면 빈 스택이므로 삭제할 수 없다. 그렇지 않으면 `array[top]`의 값을 보관하고 `top`을 1 감소시킨 뒤, 보관한 값을 반환한다.

삭제할 때 배열에 남아 있는 값을 실제로 지우지 않아도 된다. `top`보다 뒤에 있는 값은 스택에 포함되지 않는 것으로 처리하기 때문이다.

### 스택에 데이터를 추가하고 삭제하는 데 드는 시간이 얼마나 되는지와 그 이유를 설명하시오

고정 크기 배열로 구현한 스택에서 `push`와 `pop`은 모두 O(1)이다. 맨 위 원소만 다루므로 다른 데이터를 이동할 필요가 없고, 데이터 개수와 관계없이 일정한 횟수의 작업만 수행하기 때문이다.

## 트리

### 이진 트리가 무엇인지 설명하시오

이진 트리는 각 노드가 왼쪽 자식과 오른쪽 자식을 최대 하나씩 가지는 트리이다. 루트 노드를 제외한 각 노드는 부모를 하나 가지며, 사이클이 없다. 왼쪽 자식과 오른쪽 자식은 구분된다.

### 이진 트리를 구현할 때 어떤 정보를 저장하고, 어떻게 데이터를 추가하고 삭제하는지 설명하시오

전체 노드를 리스트에 저장한다. 각 노드에는 데이터, 왼쪽 자식 인덱스(left), 오른쪽 자식 인덱스(right)를 저장한다. 트리 전체에 대해서는 루트의 인덱스(root)를 저장한다. 자식이 없으면 `-1`로 없음을 표시한다.

- 추가: 새 노드를 만들고 데이터를 저장한 뒤, 두 자식 인덱스를 `-1`로 초기화한다. 트리가 비어 있으면 새 노드를 루트로 설정한다. 그렇지 않으면 지정된 부모의 비어 있는 왼쪽 또는 오른쪽 자식에 연결한다.
- 삭제: 리프 노드는 부모가 해당 노드를 가리키는 참조를 `-1`로 바꾸어 삭제한다. 자식이 하나라면 부모가 그 자식을 직접 가리키도록 연결할 수 있다. 자식이 둘이면 서브트리 전체를 삭제하거나, 규칙을 정해서 노드를 재연결해야 한다.

### 이진 트리에 수식을 어떻게 저장할 수 있는지와, 숫자/연산자 리스트로 저장된 수식을 어떻게 수식 트리로 만들 수 있는지 설명하시오

수식을 수식 트리(expression tree)로 저장한다. 숫자는 리프 노드에, 이항 연산자는 내부 노드에 저장한다. 연산자의 왼쪽 서브트리는 왼쪽 피연산자, 오른쪽 서브트리는 오른쪽 피연산자를 나타낸다.

예를 들어 `1 + 2 * 3`는 다음과 같이 저장한다.

```text
    +
   / \
  1   *
     / \
    2   3
```

숫자와 연산자 리스트가 중위 표기법으로 주어졌다면, 괄호와 연산자 우선순위를 반영하여 후위 표기법으로 변환한 뒤 스택으로 트리를 만들 수 있다. 위 수식의 후위 표기법은 `1 2 3 * +`이다.

후위 표기법 리스트를 왼쪽부터 읽으며 다음을 반복한다.

1. 숫자를 만나면 숫자 노드를 만들어 스택에 넣는다.
2. 이항 연산자를 만나면 스택에서 노드 두 개를 꺼낸다. 먼저 꺼낸 노드를 오른쪽 자식, 나중에 꺼낸 노드를 왼쪽 자식으로 삼는다.
3. 연산자 노드를 만들어 두 자식을 연결한 뒤 스택에 넣는다.
4. 모든 토큰을 처리하고 스택에 남은 하나의 노드가 수식 트리의 루트이다.

### 이진 트리에 저장되어 있는 수식을 어떻게 계산할 수 있는지 설명하시오

수식 트리를 후위 순회(postorder) 방식으로 계산한다.

1. 현재 노드가 숫자이면 그 값을 반환한다.
2. 연산자이면 왼쪽 서브트리를 재귀적으로 계산한다.
3. 오른쪽 서브트리를 재귀적으로 계산한다.
4. 두 결과에 현재 노드의 연산자를 적용하여 반환한다.

예를 들어 위 트리는 `2 * 3 = 6`을 먼저 계산한 다음, `1 + 6 = 7`을 계산한다. 

### 주어진 inorder와 preorder로 이진 트리를 그리고 구하는 과정을 설명하시오

- 중위 순회(inorder): `H D I B J E K A L F M C N G O`
- 전위 순회(preorder): `A B D H I E J K C F L M G N O`

전위 순회는 루트 → 왼쪽 → 오른쪽, 중위 순회는 왼쪽 → 루트 → 오른쪽 순서이다. 따라서 전위 순회의 첫 원소로 루트를 찾고, 중위 순회에서 그 루트를 기준으로 왼쪽과 오른쪽 서브트리를 나눈다.

1. 전위 순회의 첫 원소 `A`가 전체 루트이다. 중위 순회에서 `A`의 왼쪽인 `H D I B J E K`가 왼쪽 서브트리, 오른쪽인 `L F M C N G O`가 오른쪽 서브트리이다.
2. 왼쪽 서브트리의 전위 순회 첫 원소는 `B`이다. 중위 순회에서 `B`를 기준으로 나누면 왼쪽은 `H D I`, 오른쪽은 `J E K`이다.
3. 같은 방법으로 `D`의 왼쪽·오른쪽 자식은 `H`, `I`이고, `E`의 왼쪽·오른쪽 자식은 `J`, `K`이다.
4. 오른쪽 서브트리의 루트는 `C`이다. 중위 순회에서 `C`를 기준으로 나누면 왼쪽은 `L F M`, 오른쪽은 `N G O`이다.
5. 따라서 `F`의 왼쪽·오른쪽 자식은 `L`, `M`이고, `G`의 왼쪽·오른쪽 자식은 `N`, `O`이다.

완성된 트리는 다음과 같다.

```text
              A
           /     \
          B       C
         / \     / \
        D   E   F   G
       / \ / \ / \ / \
      H  I J K L M N  O
```

## 그래프

### 그래프가 무엇이고, 어떤 정보를 저장하는지 설명하시오

그래프는 정점(vertex)의 집합과 정점 사이를 연결하는 간선(edge)의 집합으로 이루어진 자료구조이다. 정점은 대상, 간선은 대상 사이의 관계를 나타낸다. 간선은 방향이나 가중치를 가질 수 있다.

그래프에는 정점의 식별자와 데이터, 간선으로 연결된 정점 정보, 필요한 경우 간선의 정보를 저장한다. 대표적인 저장 방식은 다음과 같다.

- 인접 행렬: 정점이 `V`개이면 `V × V` 배열을 만들고, `matrix[u][v]`에 정점 `u`와 `v` 사이의 간선 정보를 저장한다. 
- 인접 리스트: 각 정점마다 연결된 이웃 정점의 목록을 저장한다. 간선의 정보가 있으면 이웃 정점과 함께 저장한다. 

무방향 그래프의 간선 `(u, v)`는 두 정점의 이웃 목록에 각각 저장한다. 방향 그래프에서는 보통 출발 정점의 목록에 도착 정점을 저장한다.

### 단절점이 무엇이고, 그래프에서 단절점을 어떻게 찾을 수 있는지 설명하시오

단절점(articulation point)은 무방향 그래프에서 그 정점과 연결된 간선을 제거했을 때 연결 요소의 개수가 증가하는 정점이다.

DFS를 수행하면서 각 정점 `u`에 다음 정보를 저장한다.

- `disc[u]`: DFS에서 정점 `u`를 처음 방문한 순서.
- `low[u]`: `u`의 DFS 서브트리에서 트리 간선을 따라 내려간 뒤, 부모로 되돌아가는 간선을 제외한 역방향 간선을 최대 하나 사용하여 도달할 수 있는 정점의 최소 방문 순서.

정점 `u`를 방문하면 `disc[u]`와 `low[u]`를 현재 방문 순서로 초기화한다. 그 후에 각 이웃 `v`를 확인한다.

1. `v`가 미방문 정점이면 DFS를 재귀 호출한다. 탐색이 끝나면 `low[u] = min(low[u], low[v])`로 갱신한다.
2. `v`가 이미 방문했고 `u`의 부모가 아니라면 `low[u] = min(low[u], disc[v])`로 갱신한다.
3. 다음 조건으로 단절점을 판별한다.
   - DFS 루트: DFS 트리의 자식이 두 개 이상이면 단절점이다.
   - 루트가 아닌 정점 `u`: 자식 `v` 중 `low[v] >= disc[u]`인 자식이 하나라도 있으면 단절점이다.

`low[v] >= disc[u]`라는 것은 `v`의 서브트리가 `u`를 거치지 않고 `u`의 조상으로 올라갈 수 없다는 뜻이다. 따라서 `u`를 제거하면 해당 서브트리가 분리된다.
