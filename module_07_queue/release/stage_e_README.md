# Module 7 — Stage E: Lab and Evidence

Start with `student/lab.md`, then edit only:

- the three numbered `TODO` sections in `code/starter/event_queue.c`; and
- the three `TODO` test sections in `code/tests/test_student.c`.

`TODO` marks an unfinished section that the student must complete.

The Queue capacity is selected once at setup. Students validate its stored
state, implement enqueue and dequeue with a fixed amount of work, and never
shift events. The autopsy—a careful investigation after a failure—is
standalone and checks every array position before using it.

Submit the files and evidence listed in the lab, then complete
`student/evidence_template.md`.
