# Module 1 — Stage D: Calibrated Notes

Use these materials after completing the investigation and Meeting A exit
ticket.

- `textbook.md` and `textbook_korean.md` provide English and Korean editions
  of the fixed-array chapter, including **Full C Code Explanation**.
- `notes.md` summarizes that model and connects it to the lab.
- `diagrams/memory_models.md` supplies diagrams and text equivalents.

Choose either textbook language. The full C explanation is optional help:
look up one symbol or operation when it blocks your reading. `notes.md`
maps questions to its eleven topics. There is no requirement to read every
topic or submit the appendix's practice answers.

The separate lab autopsy is released in Stage E, when you will preserve your
own prediction before running its demonstration.

Annotate earlier responses with corrections instead of erasing them.
