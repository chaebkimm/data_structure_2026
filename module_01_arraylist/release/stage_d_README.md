# Module 1 — Stage D: Calibrated Notes

Use these materials after completing the investigation and Meeting A exit
ticket.

- `textbook.md` and `textbook_korean.md` provide English and Korean editions
  of the fixed-array concepts and short C examples.
- `notes.md` summarizes that model and connects it to the lab.
- `diagrams/memory_models.md` supplies diagrams and text equivalents.

use **Ask GPT** beside the relevant section on the webpage. `notes.md`
summarizes the model and traces the examples so you can compare the answer
with the code and your own prediction.

own prediction before running its demonstration.
