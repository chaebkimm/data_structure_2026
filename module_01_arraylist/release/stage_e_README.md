# Module 1 — Stage E: Lab and Evidence

Start with `student/lab.md`, then edit only:

- `code/starter/int_list.c`;
- `code/tests/test_student.c`.

Checked indexed read/update, first-match find, append, insert, and remove are
all core. The extension suite adds boundary and sequence cases for those same
operations. Do not edit supplied tests to hide a failure.

The isolated Bounds and Invariant Autopsy uses a guard slot to show a faulty
full-array check safely; it is not part of the passing core suite. Submit the
artifacts listed in the lab and complete `student/evidence_template.md`.
