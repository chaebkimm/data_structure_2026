# 1장. 데이터를 한곳에 모아 두기

## 논리적으로 생각해 보기

### 데이터를 한곳에 모아 두면 무엇이 좋을까?

모든 데이터에 같은 작업을 수행하려 할 때, 데이터를 한곳에 모아 두면 항목을 하나씩 차례대로 처리하기 쉽다.

### 가장 간단한 방법

저장할 데이터의 개수를 미리 알고 있다면, 처음부터 그만큼의 메모리 공간을 정확히 확보하면 된다.

### 데이터를 어떻게 추가할까?

새 데이터는 기존 데이터의 끝에 이어서 저장하면 된다. 기존 데이터의 중간에 추가하려면 삽입할 위치부터 뒤에 있는 모든 데이터를 오른쪽으로 한 칸씩 이동한다. 그런 다음 새로 생긴 빈자리에 새 데이터를 저장한다.

### 어떤 메타데이터가 필요할까?

저장된 항목의 전체 개수를 기록해 두면, 데이터가 저장된 메모리 영역과 아직 사용하지 않은 빈 공간을 쉽게 구분할 수 있다.

### 데이터를 추가할 때 무엇을 확인해야 할까?

먼저 현재 항목 수와 전체 용량을 비교하여 배열에 새 항목을 저장할 공간이 있는지 확인한다. 그런 다음 삽입하려는 위치가 유효한 범위 안에 있는지 확인한다.

### 메모리 공간이 가득 차면 어떻게 될까?

공간이 가득 차면 항목을 더 추가할 수 없다.

### 특정 위치의 데이터를 어떻게 읽을까?

위치로부터 정확한 메모리 주소를 계산한 다음, 그곳으로 곧바로 이동한다.

### 특정 값을 가진 데이터를 어떻게 찾을까?

맨 앞에서 시작하여 값이 일치하는 항목을 찾을 때까지 하나씩 확인한다.

### 데이터를 어떻게 삭제할까?

삭제로 생긴 빈자리를 없애기 위해 삭제된 항목 뒤의 모든 데이터를 왼쪽으로 한 칸씩 이동한다.

## 효율 계산해 보기

### 메모리 효율

저장된 항목의 개수와 관계없이 배열은 전체 용량만큼의 메모리를 확보한다.

### 데이터 추가의 효율

이동해야 하는 항목의 개수에 따라 작업량이 늘어난다. 평균적으로 이 작업량은 저장된 전체 항목 수에 비례한다.

### 위치로 데이터를 찾는 효율

위치로부터 메모리 주소를 계산하므로 작업량은 일정하다.

### 값으로 데이터를 찾는 효율

확인해야 하는 항목의 개수에 따라 작업량이 늘어난다. 평균적으로 이 작업량은 저장된 전체 항목 수에 비례한다.

### 데이터 삭제의 효율

이동해야 하는 항목의 개수에 따라 작업량이 늘어난다. 평균적으로 이 작업량은 저장된 전체 항목 수에 비례한다.

## 용어 정리

### 연속된 메모리(Contiguous memory)

메모리 공간이 끊김 없이 바로 옆에 이어져 있는 상태이다. 연속 저장 공간(contiguous storage) 또는 연속된 메모리 위치(consecutive memory locations)라고도 한다.

### 배열(Array)

일정한 개수의 항목을 저장하기 위해 고정된 크기의 메모리 공간을 미리 확보하는 자료구조이다.

이 장에서 사용하는 배열은 고정 크기 배열(fixed-size array) 또는 고정 길이 배열(fixed-length array)이라고도 한다. 배열의 전체 칸 수는 변하지 않는다.

### 리스트(List)

데이터에 순서를 부여해서 저장하는 자료구조이다. 이 문맥에서는 시퀀스(sequence)라고도 한다. 순서가 있다는 것은 각 항목에 위치가 있다는 뜻이다. 값이 크기순으로 정렬되어 있다는 뜻은 아니다.

### 배열 리스트(Array list)

배열로 구현한 리스트이다. 배열 기반 리스트(array-based list)라고도 하며, 영어로 ArrayList라고 붙여 쓰기도 한다.

용량이 고정된 배열(fixed-capacity array)을 사용할 수도 있고, 저장 공간을 늘릴 수 있는 버전인 동적 배열(dynamic array) 또는 크기 조절이 가능한 배열(resizable array)을 쓸 수도 있다.

### 인덱스(Index)

데이터의 위치를 나타내는 번호이다. 첨자(subscript) 또는 위치(position)라고도 한다. 흔히 인덱스는 0부터 시작한다.

### 원소(Element)

배열이나 리스트에 저장된 데이터 하나이다. 항목(item) 또는 엔트리(entry)라고도 한다.

### 크기(Size)

자료구조에 현재 저장된 원소의 실제 개수이다. 원소 수(element count), 항목 수(item count), 리스트 길이(list length)라고도 한다.

여기서 크기는 바이트 수가 아니라 저장된 원소 수를 뜻한다. 리스트를 구현하는 배열의 길이는 전체 칸 수이므로 용량과 같다.

### 용량(Capacity)

배열에 저장할 수 있는 원소의 최대 개수이다. 할당된 칸 수(allocated slot count)라고도 한다. 용량이 고정된 리스트에서는 크기의 최댓값이기도 하다.

## 규칙

### 이 자료구조의 규칙은 무엇일까?

데이터 중간에 비어있는 공간이 없고, 메모리의 앞에서부터 저장한다.

### 규칙을 지키면 무엇이 좋을까?

데이터의 순서로 메모리 주소를 계산해서 한 번에 데이터를 찾을 수 있다.

### 데이터를 추가할 때 어떻게 규칙을 지킬까?

기존 데이터의 끝이나 중간에만 추가한다. 중간에 추가할 때는 자리를 확보하기 위해 기존 데이터를 한 칸씩 오른쪽으로 이동한다.

### 데이터를 삭제할 때 어떻게 규칙을 지킬까?

삭제해서 발생한 비어있는 공간을 메우기 위해 뒤에 있는 모든 데이터를 왼쪽으로 한 칸씩 이동한다.

### 규칙이 깨지면 어떻게 될까?

메모리 중간에 비어 있는 공간이 있으면 리스트에서의 인덱스와 실제 배열에서의 인덱스가 어긋난다. 그 결과, 리스트에서의 인덱스로 메모리 주소를 계산할 수 없다. 비어있는 공간과 데이터를 구분할 수도 없다.

## 코딩 계획

### 배열에 데이터 저장하기

- 배열 선언: 고정된 용량을 정하고 그만큼의 메모리 칸을 확보한다.
- 위치 선택: 아직 데이터가 저장되지 않은 메모리 공간 중 가장 앞의 번호를 선택한다.
- 데이터 저장: 선택한 번호에 데이터를 저장한다.
- 데이터 개수 갱신: 저장된 데이터의 전체 개수를 1 증가시킨다.

### 특정 번호의 데이터 읽기 또는 변경하기

- 번호 확인: 원하는 번호에 데이터가 실제로 저장되어 있는지 확인한다.
- 값 읽기: 배열의 해당 번호에 저장된 값을 읽는다.
- 값 변경: 해당 번호에 저장된 값을 새 값으로 바꾼다.

### 값으로 데이터 찾기

- 찾을 값 선택: `target`에 찾으려는 값을 저장한다.
- 값 비교: `index = 0`부터 시작하여 `index < size`인 동안 저장된 항목을 하나씩 `target`과 비교한다.
- 일치하면 중단: 값이 일치하면 `break`로 반복문을 끝낸다. 처음 일치한 항목의 위치가 `index`에 남는다.
- 일치하는 값이 없는 경우: 일치하는 값을 찾지 못하고 반복문이 끝나면 `index`는 `size`와 같다.

### 특정 번호의 데이터 삭제하기

- 번호 확인: 해당 번호에 데이터가 실제로 저장되어 있는지 확인한다.
- 데이터 이동: 삭제할 위치 다음에 있는 모든 데이터를 왼쪽으로 한 칸씩 이동시킨다.
- 개수 줄이기: 데이터의 전체 개수를 1 감소시킨다.

데이터를 왼쪽으로 이동할 때 맨 오른쪽 데이터부터 옮기면 기존 데이터가 덮어씌워지므로, 맨 왼쪽 데이터부터 차례대로 이동시킨다.

### 특정 번호에 데이터 추가하기

- 번호 및 용량 확인: 남은 메모리 공간이 있는지, 추가할 위치가 기존 데이터와 이어지는지 확인한다.
- 데이터 이동: 추가할 위치를 포함해 그 뒤에 있는 모든 데이터를 오른쪽으로 한 칸씩 이동시킨다.
- 데이터 저장: 새로 비워진 위치에 새 데이터를 추가한다.
- 개수 늘리기: 데이터의 전체 개수를 1 증가시킨다.

데이터를 오른쪽으로 이동할 때 맨 왼쪽 데이터부터 옮기면 기존 데이터가 덮어씌워지므로, 맨 오른쪽 데이터부터 차례대로 이동시킨다.

## 새로운 C 문법 설명

### `[capacity]`(배열 생성하기)

C에서 배열을 만들려면 변수 이름 뒤에 대괄호 `[]`를 사용한다. 대괄호 안에는 저장하려는 항목의 개수를 쓴다. 예를 들어 `int array[10];`은 정수 10개를 저장할 수 있는 연속된 메모리 공간을 확보하라는 뜻이다. 공간의 크기가 고정되므로 필요한 최대 용량을 처음부터 정해야 한다.

### `[index]`(데이터에 접근하기)

배열을 만든 뒤에는 대괄호를 사용하여 배열 안의 데이터를 읽거나 변경한다. 대괄호 안에는 원하는 항목의 번호를 쓴다. C에서는 1이 아니라 0부터 번호를 센다. `array[0]`으로 첫 번째 항목에 접근하고, `array[1]`로 두 번째 항목에 접근한다.

## C 코드

### 배열에 데이터 저장하기

```c
/* 고정된 저장 공간 선언 */
int array[10] = {100, 200, 300, 400, 500, 0, 0, 0, 0, 0};
int array_capacity = 10;

/* 항목 개수 설정 */
int size = 5;

/* 항목에 접근할 위치 */
int pos;
```

### 특정 번호의 데이터 읽기 또는 변경하기

```c
pos = 1;

/* 번호 확인 */
if (pos >= 0 && pos < size) {

        /* 데이터 읽기 */
        int data = array[pos];

        /* 데이터 변경하기 */
        array[pos] = 500;
}
```

### 값으로 데이터 찾기

```c
/* 찾을 값 */
int target = 300;

/* 결과를 저장할 위치 */
int index;

for (index = 0; index < size; index = index + 1) {
        if (array[index] == target) {
                break;
        }
}
```

### 특정 번호의 데이터 삭제하기

```c
/* 번호 확인 */
if (pos >= 0 && pos < size) {

        /* 데이터를 왼쪽으로 이동 */
        for (int i = pos + 1; i < size; i = i + 1) {
                array[i - 1] = array[i];
        }

        /* 개수 줄이기 */
        size = size - 1;
}
```

### 특정 번호에 데이터 추가하기

```c
/* 번호 확인 */
if (pos >= 0 && pos <= size && size < array_capacity) {

        /* 데이터를 오른쪽으로 이동 */
        for (int i = size - 1; i >= pos; i = i - 1) {
                array[i + 1] = array[i];
        }

        /* 데이터 저장 */
        array[pos] = 600;

        /* 개수 늘리기 */
        size = size + 1;
}
```
