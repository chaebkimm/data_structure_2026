# Module 09 — Stage A: Find Stored Values

Complete one prompt in `module_09_hash_table/student/` before opening later
materials. The standard and linear forms ask the same questions using the
same numbers. Preserve predictions before comparing them with a reference.

Begin with searching an array for one value, then remember input positions
at places equal to those values. Consider negative and large values before
exploring bounded remainder groups and linked records. Keep the pair-sum
application until the final section, after the storage and lookup questions.
Drawing quality and arithmetic speed are not assessed.
