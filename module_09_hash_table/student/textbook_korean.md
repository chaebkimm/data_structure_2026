# 9장. 키로 데이터 저장하고 찾기

배열은 데이터마다 정해진 번호가 있어서 번호로 데이터를 찾을 수 있다. 번호에 의미를 부여해서 데이터를 찾는 키로 사용하면, 의미를 가지고 원하는 데이터를 쉽게 찾을 수 있다.

## 논리적으로 생각해 보기

### 메모리 공간에서 원하는 값을 어떻게 찾을까?

단순한 방법은 모든 데이터를 처음부터 하나씩 읽으면서 원하는 값인지 확인하는 것이다. 값이 있을 때는 어디에 있는지 알 수 있고, 값이 없을 때는 없다는 사실을 알 수 있다.

### 더 쉽게 찾는 방법은 무엇일까?

가능한 모든 값마다 칸이 있는 표를 만들고, 저장된 값이 어디에 있는지를 기록해 둔다. 그리고 값을 표의 번호로 사용해서 원하는 값에 해당하는 칸만 확인한다. 값이 있을 때는 어디에 있는지 알 수 있고, 값이 없을 때는 없다는 사실을 알 수 있다. 

### 값의 범위가 넓을 때는 어떻게 할까?

값의 범위가 표의 용량을 넘어가면, 값에 적절한 연산을 해서 표에 맞는 번호를 구할 수 있다. 번호와 값이 달라졌기 때문에 표에 값도 함께 기록해야 원하는 값에 해당하는 정보인지 알 수 있다.

### 서로 다른 값의 번호가 같을 때는 어떻게 할까?

번호가 같은 값들은 리스트를 만들어서 표에 저장한다. 리스트의 크기를 미리 알기 어렵기 때문에 링크드 리스트가 적절하다. 원하는 값을 찾을 때는 해당 번호에 있는 리스트 안에서만 확인하면 된다. 

### 다른 해결책은 무엇이 있을까?

값을 저장하려고 할 때 해당 번호의 칸이 차 있으면, 미리 정한 규칙에 따라 다른 비어 있는 칸으로 이동할 수도 있다. 원하는 값을 찾을 때는 해당 번호의 칸에서부터 정해진 규칙에 따라 이동하며 찾는다. 칸이 비어 있으면 값이 없다는 것을 알 수 있다.

### 합계가 목표값인 두 숫자를 어떻게 찾을까?

메모리 공간에 저장되어 있는 숫자들 중에서 더한 결과가 목표값과 같은 두 숫자를 찾아보자. 가장 단순한 방법은 가능한 경우를 모두 확인하는 무차별 대입 방법이다. 각 숫자를 나머지 모든 숫자와 하나씩 더해 보면 가능한 모든 숫자 쌍을 확인할 수 있다. 덧셈은 순서와 상관없으므로 각 숫자를 앞에서 봤던 숫자들과만 더해 봐도 된다.

### 각 숫자마다 어떤 숫자를 찾으면 될까?

현재 숫자와 더해서 목표값이 되려면, 찾아야 할 숫자는 목표값에서 현재 숫자를 뺀 값이다. 현재 숫자를 앞에서 봤던 숫자들과 일일이 더해 보는 대신, 그중에 이 값이 있는지만 찾으면 된다.

### 숫자를 찾을 때 표를 어떻게 적용할까?

앞에서 봤던 숫자들을 표에 저장해 두면 된다. 숫자들을 하나씩 읽으며 목표값에서 현재 숫자를 뺀 값을 표에서 찾아 보고, 없으면 현재 숫자를 표에 추가한다. 숫자마다 표에서 해당하는 칸만 확인하면 되므로 속도가 향상된다. 

## 효율 계산해 보기

### 하나씩 읽어서 찾는 시간 비용은 얼마일까?

원하는 값이 저장되어 있을 때는 평균적으로 보면 전체 데이터의 절반 정도를 읽으면 찾을 수 있다. 원하는 값이 없을 때는 항상 모든 데이터를 확인하게 된다. 따라서 찾는 데 필요한 시간은 데이터 개수에 비례해서 늘어난다.

### 표를 써서 찾는 비용은 얼마일까?

가능한 모든 값마다 칸이 있는 표를 쓰면, 값에 해당하는 칸 하나만 확인하면 되므로 데이터 개수와 상관없이 일정한 시간이 든다. 하지만 실제 저장된 데이터 개수와 상관없이 값의 범위가 넓을수록 메모리 공간이 많이 필요하다.

### 번호가 같은 값이 많아지면 어떻게 될까?

값에 연산을 해서 번호를 구하면 표의 용량을 작게 할 수 있지만, 서로 다른 값의 번호가 같아질 수 있다. 표의 용량이 충분하고 번호가 고르게 나뉘면 겹치는 일이 적어, 여전히 데이터 개수와 상관없이 거의 일정한 시간에 찾을 수 있다. 하지만 번호가 같은 값이 많아질수록 확인해야 할 데이터가 늘어나며, 최악의 경우 모든 값의 번호가 같으면 하나씩 읽는 경우와 시간 비용이 같아진다.

### 합계가 목표값인 두 숫자를 찾는 비용은 얼마일까?

무차별 대입 방법은 각 숫자를 앞에서 봤던 숫자들과 모두 더해 보므로 숫자 개수의 제곱에 비례하는 시간이 든다. 추가로 드는 메모리 공간은 거의 없다. 표를 사용하는 방법은 번호가 고르게 나뉘면 찾아야 할 숫자에 해당하는 칸만 표에서 확인하므로, 숫자 개수에 비례하는 시간이 든다. 대신 숫자 개수 정도 용량의 표를 만들 메모리 공간이 필요하다.

## 용어 정리

### 키(key)

데이터를 찾는 데 사용하는 값이다.

### 직접 주소 테이블(direct-address table)

가능한 모든 값마다 칸을 만들어 값을 그대로 번호로 사용하는 표다.

### 해싱(hashing)

어떤 데이터가 주어지든 연산을 해서 일정한 범위의 결과를 구하는 것이다. 

### 해시 함수(hash function)

데이터에 연산을 해서 일정한 범위의 결과를 구하는 함수다.

### 해시 값(hash value)

데이터에 해시 함수를 적용해서 구한 결과다. 

### 해시 테이블(hash table)

해시 값을 번호로 데이터를 저장하고 찾는 표다. 

### 버킷(bucket)

해시 테이블의 칸이다. 슬롯(slot)이라고도 한다. 

### 충돌(collision)

서로 다른 값의 번호가 같은 현상이다.

### 체이닝(chaining)

충돌이 생기면 값들을 링크드 리스트로 만들어 표에 저장하는 해결책이다.

### 개방주소법(open addressing)

충돌이 생기면 정해진 규칙에 따라 다른 비어 있는 칸으로 이동하는 해결책이다. 칸을 옮겨 가며 확인하는 것을 탐사(probing)라고 한다.

### 무차별 대입(brute force)

가능한 경우를 모두 확인하는 방법이다.

## 규칙

### 해시 테이블에서 쓰는 해시 함수는 어떤 규칙을 지켜야 할까? 

해시 테이블에서 쓰는 해시 함수는 그 표에 맞는 번호를 결과로 낸다. 또한 같은 데이터에 대해 항상 같은 결과를 낸다. 

### 규칙을 지키면 무엇이 보장될까?

해시 값이 표에 맞는 번호이므로, 해당하는 칸이 표에 반드시 있다. 같은 데이터의 해시 값은 항상 동일하므로, 저장한 데이터를 해시 값으로 다시 찾을 수 있다.

### 규칙을 깨면 무엇이 잘못될까?

해시 값의 범위가 표에 맞지 않으면, 해당하는 칸이 표에 없어서 데이터를 저장할 수 없다. 같은 데이터의 해시 값이 달라지면, 데이터가 저장된 칸을 해시 테이블에서 찾을 수 없다. 

## 코딩 계획

### 해시 테이블에 저장할 노드 설계하기

노드는 데이터를 저장하고, 데이터를 식별하는 데 쓸 키도 저장한다. 링크드 리스트를 구성하기 위해 다른 노드의 위치도 저장해 둔다.

### 노드를 저장할 배열 리스트 만들기

노드들을 저장할 배열을 만들고 노드가 몇 개 저장되어 있는지 기록한다. 새 노드는 노드 리스트의 끝에 추가한다.

### 해시 테이블의 용량 정하고 만들기

해시 테이블의 용량과 노드의 개수가 같으면 한 칸에 노드가 평균 하나씩 연결된다. 용량을 조금 더 크게 하면 평균 노드 개수가 1개 미만이 되어 시간 비용이 충분히 낮아진다. 칸마다 리스트의 시작 노드 위치를 기록할 해시 테이블을 만든다. 초기값으로는 노드 위치가 될 수 없는 `-1`을 저장해 모든 칸에 노드가 없다는 표시를 해 둔다.

### 해시 함수 만들기

키에 해당하는 해시 테이블 번호를 구하는 해시 함수를 만든다. 키를 해시 테이블의 용량으로 나눈 나머지를 구하되, 음수이면 용량을 더해서 항상 표에 맞는 번호를 결과로 낸다.

### 해시 테이블에 키와 데이터 저장하기

키와 데이터로 새 노드를 만들어 노드 리스트에 저장한다. 키의 해시 값에 해당하는 칸에 연결된 링크드 리스트에 새 노드를 제일 앞에 추가한다. 칸에는 새 노드의 위치를 기록한다. 

### 해시 테이블에서 키로 노드 찾기

키의 해시 값에 해당하는 칸에 연결된 링크드 리스트의 노드를 하나씩 따라가며 키를 비교해서 원하는 노드를 찾는다.

### 무차별 대입법으로 합계가 목표값인 두 숫자 찾기

각 숫자에 대해 반복하고, 그 안에서 앞에서 봤던 숫자들에 대해 반복한다. 두 숫자를 더해서 목표값과 같은지 확인한다.

### 해시 테이블로 합계가 목표값인 두 숫자 찾기

각 숫자에 대해 반복하고, 목표값에서 현재 숫자를 뺀 결과를 키로 해시 테이블에서 찾는다. 없으면 현재 숫자를 키로 해시 테이블에 저장한다. 

## 새로운 C 문법 설명

### 정수 상수 식

정수 상수끼리 계산하는 수식을 정수 상수 식이라고 한다. 컴퓨터가 코드를 번역할 때 이미 값이 정해져 있기 때문에, `enum`으로 상수 이름을 붙일 수 있다. 

### 음수의 나머지

C에서 정수 나눗셈은 몫의 소수점 이하를 버려서 `0`에 가까운 쪽으로 맞춘다. 그래서 음수를 나누면 나머지가 음수일 수 있다. 

### 뒤에서부터 거꾸로 방문하는 반복

`for (int j = i - 1; j >= 0; j--)`는 `j`를 `i - 1`부터 `0`까지 반복한다.

## C 코드

### 노드 리스트 만들기

키와 데이터를 구분해서 저장하는 노드 구조체를 만든다. 구조체에는 다음 노드의 위치도 저장하는데, 이 위치는 노드 리스트에서의 인덱스다. 배열과 저장된 노드 개수로 배열 리스트를 만든다.

```c
/* 노드 리스트에서 쓸 상수 */
enum { NODES_CAPACITY = 10 };

/* 노드 구조체 */
struct hnode {
    int key;
    int data;
    int next;
};

/* 노드를 저장할 배열 리스트 */
struct hnode hnodes[NODES_CAPACITY];
int size = 0;
```

### 노드를 새로 만들기

키, 데이터, 다음 노드 위치를 입력받아서 노드를 새로 만든다. 노드 리스트의 끝에 추가하고 새 노드의 인덱스를 결과로 낸다. 노드 리스트가 꽉 차 있으면 노드를 만들지 않고 `-1`을 결과로 낸다. 

```c
/* 노드 만들기 */
int new_hnode(int _key, int _data, int _next) {
    /* 노드 리스트 용량 확인 */
    if (size >= NODES_CAPACITY) {
        return -1;
    }
    /* 노드 리스트에서 마지막 노드 뒤에 비어 있는 칸 인덱스를 구하고 크기 증가 */
    int i = size++;
    /* 새 노드에 정보 저장 */
    hnodes[i].key = _key;
    hnodes[i].data = _data;
    hnodes[i].next = _next;
    return i;
}
```

### 해시 함수 만들기

해시 테이블의 용량을 노드 리스트 용량의 1.5배로 정한다. 키를 해시 테이블의 용량으로 나눈 나머지를 구한다. 나머지가 음수이면 용량을 더해서, 항상 해시 테이블의 인덱스로 쓸 수 있는 값을 결과로 낸다.

```c
/* 해시 테이블에서 쓸 상수 */
enum { TABLE_CAPACITY = NODES_CAPACITY * 3 / 2 };

/* 해시 함수 */
int hash_func(int key) {
    /* 키를 해시 테이블 용량으로 나눈 나머지 */
    int hash = key % TABLE_CAPACITY;
    /* 나머지가 음수이면 용량을 더해서 0 이상으로 맞춤 */
    if (hash < 0) {
        hash += TABLE_CAPACITY;
    }
    return hash;
}
```

### 해시 테이블 만들고 초기화하기

칸마다 링크드 리스트의 시작 노드 인덱스를 기록할 해시 테이블을 만든다. 사용하기 전에 초기화해서 노드 리스트를 비우고, 모든 칸에 노드가 없다는 표시인 `-1`을 저장한다.

```c
/* 칸마다 링크드 리스트의 시작 노드 인덱스를 기록하는 해시 테이블 */
int hashtable[TABLE_CAPACITY];

/* 해시 테이블 초기화 */
void initialize(void) {
    /* 노드 리스트 비우기 */
    size = 0;
    /* 모든 칸에 노드가 없다는 표시 */
    for (int i = 0; i < TABLE_CAPACITY; i++) {
        hashtable[i] = -1;
    }
}
```

### 해시 테이블에 키와 데이터 저장하기

키의 해시 값에 해당하는 칸에서 링크드 리스트의 시작 노드 인덱스를 읽는다. 그 인덱스를 다음 노드 위치로 해서 새 노드를 만들면, 새 노드가 링크드 리스트의 제일 앞에 놓인다. 칸이 비어 있었다면 `-1`이 새 노드의 다음 노드 위치가 되어 링크드 리스트의 끝을 표시한다. 칸에는 새 노드의 인덱스를 기록하고 `0`을 결과로 낸다. 노드를 만들지 못했으면 해시 테이블을 바꾸지 않고 `-1`을 결과로 낸다. 

```c
/* 해시 테이블에 키와 데이터 저장 */
int insert(int k, int d) {
    /* 키의 해시 값 */
    int hash = hash_func(k);
    /* 칸에 기록되어 있던 시작 노드 인덱스 */
    int old_head = hashtable[hash];
    /* 기존 시작 노드를 다음 노드로 하는 새 노드 만들기 */
    int node = new_hnode(k, d, old_head);
    /* 노드 리스트가 꽉 차서 만들지 못한 경우 */
    if (node == -1) {
        return -1;
    }
    /* 칸에 새 노드 인덱스 기록 */
    hashtable[hash] = node;
    return 0;
}
```

### 해시 테이블에서 키로 노드 찾기

키의 해시 값에 해당하는 칸에서 링크드 리스트의 시작 노드 인덱스를 읽는다. 그 노드부터 다음 노드 위치를 따라가며 키를 비교해서, 키가 같은 노드를 찾으면 그 노드의 인덱스를 결과로 낸다. `-1`을 만나면 링크드 리스트가 끝난 것이므로, 키가 저장되어 있지 않다는 뜻으로 `-1`을 결과로 낸다.

```c
/* 해시 테이블에서 키로 노드 찾기 */
int find(int k) {
    /* 키의 해시 값 */
    int hash = hash_func(k);
    /* 칸에 기록된 시작 노드 인덱스 */
    int node = hashtable[hash];
    /* 링크드 리스트의 끝을 만날 때까지 반복 */
    while (node != -1) {
        /* 키가 같은 노드를 찾은 경우 */
        if (hnodes[node].key == k) {
            return node;
        }
        /* 다음 노드로 이동 */
        node = hnodes[node].next;
    }
    /* 키가 저장되어 있지 않은 경우 */
    return -1;
}
```

### 무차별 대입법으로 합계가 목표값인 두 숫자 찾기

숫자들을 배열에 저장하고, 찾은 두 숫자의 인덱스를 기록할 배열을 만든다. 숫자를 모두 해시 테이블에 저장할 수 있으려면 노드 리스트 용량이 숫자 개수 이상이어야 한다. 각 숫자에 대해 반복하고, 그 안에서 앞에서 봤던 숫자들을 가까운 것부터 거꾸로 방문한다. 두 숫자를 더한 결과가 목표값과 같으면 두 인덱스를 기록하고 끝낸다. 끝까지 찾지 못하면 `-1`을 기록한다.

```c
/* 숫자 개수 (노드 리스트 용량 이하여야 한다) */
enum { NUMS_SIZE = 10 };

/* 숫자들 */
int nums[NUMS_SIZE] = {-16, -8, -4, -2, -1, 1, 2, 4, 8, 16};
/* 찾은 두 숫자의 인덱스 */
int answer[2] = {-1, -1};

/* 무차별 대입법으로 합계가 목표값인 두 숫자 찾기 */
void two_sum_bf(int target) {
    /* 각 숫자에 대해 반복 */
    for (int i = 0; i < NUMS_SIZE; i++) {
        /* 앞에서 봤던 숫자들을 가까운 것부터 거꾸로 방문 */
        for (int j = i - 1; j >= 0; j--) {
            /* 두 숫자를 더한 결과가 목표값과 같은 경우 */
            if (nums[i] + nums[j] == target) {
                answer[0] = j;
                answer[1] = i;
                return;
            }
        }
    }
    /* 찾지 못한 경우 */
    answer[0] = answer[1] = -1;
}
```

### 해시 테이블로 합계가 목표값인 두 숫자 찾기

먼저 해시 테이블을 초기화한다. 각 숫자에 대해 반복하고, 목표값에서 현재 숫자를 뺀 결과를 키로 해시 테이블에서 찾는다. 찾으면 그 노드의 데이터가 앞에서 봤던 숫자의 인덱스이므로, 두 인덱스를 기록하고 끝낸다. 찾지 못하면 현재 숫자를 키로, 그 인덱스를 데이터로 해시 테이블에 저장한다. 끝까지 찾지 못하면 `-1`을 기록한다.

```c
/* 해시 테이블로 합계가 목표값인 두 숫자 찾기 */
void two_sum_ht(int target) {
    /* 해시 테이블 초기화 */
    initialize();
    /* 각 숫자에 대해 반복 */
    for (int i = 0; i < NUMS_SIZE; i++) {
        /* 찾아야 할 숫자: 목표값에서 현재 숫자를 뺀 결과 */
        int complement = target - nums[i];
        /* 찾아야 할 숫자를 키로 해시 테이블에서 찾기 */
        int node = find(complement);
        /* 찾은 경우: 노드의 데이터가 앞에서 봤던 숫자의 인덱스 */
        if (node != -1) {
            int j = hnodes[node].data;
            answer[0] = j;
            answer[1] = i;
            return;
        }
        /* 현재 숫자를 키로, 인덱스를 데이터로 저장 */
        if (insert(nums[i], i) == -1) {
            /* 노드 리스트가 꽉 차서 저장하지 못한 경우 */
            break;
        }
    }
    /* 찾지 못한 경우 */
    answer[0] = answer[1] = -1;
}
```
