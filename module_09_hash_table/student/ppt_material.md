## 배열에서 숫자를 찾는 방법

- 배열에 숫자들이 저장되어 있고, 원하는 숫자의 인덱스를 찾는 상황이다.
- 배열에 저장된 모든 숫자들을 차례대로 확인하면, 인덱스를 찾을 수 있다.

## 직통 주소 테이블

- 배열에 저장된 숫자가 0 이상이고 작다면 새로 배열을 만들어서 가능한 모든 값에 대해 기존 배열에서 인덱스를 저장하면 상수 시간 만에 찾을 수 있다.
- `nums[3] = {2, 5, 6};` 일 때,
- `table[7] = {-1, -1, 0, -1, -1, 1, 2};`

## 해시 함수

- 해시 함수는 같은 데이터에 항상 같은 값을 계산해 주는 함수다.
- 비밀번호를 저장할 때는, 그대로 저장하면 위험하므로 암호학적인 해시 함수로 해시 값을 저장해 놓고 입력받은 비밀번호의 해시 값과 비교한다.

## 해시 테이블

- 해시 함수를 쓰면 큰 숫자나 작은 숫자도 해시 값을 인덱스로 테이블에 저장할 수 있다.
- 해시 테이블에서는 같은 인덱스에 여러 숫자가 저장될 수 있어 해시 값이 같은 숫자들을 링크드 리스트로 관리한다.

## 해시 노드

- 해시 노드에는 숫자 값, 원래 배열에서의 인덱스, 다음 노드 정보를 저장한다.
- 해시 테이블에는 해시 값마다 해당 해시 노드로 구성된 링크드 리스트의 처음 노드 정보를 저장한다.

## 배열만으로 만든 해시 테이블

- 링크드 리스트 방식을 쓰는 대신 자리가 없으면 미리 정해 놓은 규칙에 따라 저장할 곳을 찾아가게 만들 수 있다.
- 해시 함수를 아는 공격자가 해시 값이 같은 많은 데이터를 저장하면 다른 해시 값들도 저장할 공간을 찾아다니게 된다.

## 로빈 후드 해시 테이블

- 특정 데이터만 찾는 데 오랜 시간이 걸리는 상황을 방지하기 위해서 더 멀리 찾아온 간절한 데이터에 공간을 양보하는 방식이 널리 쓰이는 기법이다.
- 양보한 데이터가 다른 자리를 찾아간다.

## 합이 목표치인 두 숫자를 찾는 법

- 목표치가 t일 때, 배열에서 숫자 n을 하나씩 읽으며, 이전에 읽은 숫자 중에서 t - n이 있었는지 해시 테이블로 확인하면 된다.
- 없었으면 다음 반복들에서 확인할 수 있게 n을 해시 테이블에 추가한다.
