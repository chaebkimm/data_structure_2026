# Module 6 — Stage D: Beginner Textbook and Models

The current Stage D files explain the array-based edge-list and
biconnected-component lab. Use them as enrichment for the separate
checked adjacency-matrix DFS exercise in Stages A–C and E. They do not
specify Stage E's three TODOs, typed vertex-Stack behavior, status codes,
or failure-preservation contracts. For those requirements, see the
repository references `module_06_graph_dfs/student/lab.md` and
`module_06_graph_dfs/code/include/`. They are not bundled in Stage D.

The current classroom path, including the array-lab workbook and lecture
driver, is listed in the repository reference `module_06_graph_dfs/README.md`,
which is not bundled in Stage D.

Open these materials after completing and preserving the Stage C core.

- `textbook.md` follows the array lab's edge indexing, saved low-link
  values, and the parent's block-boundary check immediately after each child
  returns. The coding reference uses
  the current `edges[45]` and `bcc[9][45]` storage with the reused ten-entry
  pending-edge stack; indexing, low-link calculation, and extraction are
  separate passes.
- `diagrams/dfs_models.md` supplies diagrams and exact text equivalents.
