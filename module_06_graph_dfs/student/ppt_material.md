# 간선을 저장하는 방법

- 간선 리스트: 노드 리스트처럼 간선들을 모아놓은 리스트. 장점은 간선마다 인덱스가 부여됨.
- 인접 행렬: 두 노드를 잇는 간선 정보를 제공하는 이차원 배열. 장점은 간선을 쉽게 찾을 수 있음.

# 무방향 그래프의 간선 저장

- 간선 리스트: 각 데이터에 간선의 양 쪽 노드를 저장. 간선을 중복해서 저장하지 않음.
- 인접 행렬: 행과 열이 모두 노드. 무방향 그래프에서는 대각선을 기준으로 행렬이 대칭.

# 재귀 호출로 그래프 간선 탐색

- 현재 노드의 이웃들에 대해서 반복.
- preorder 시점에 방문 번호를 저장.
- 현재 노드의 parent와 이웃의 방문 번호를 보고 이웃을 구별하고, 이웃의 종류에 따라 적절한 작업 수행.

# 이웃 노드의 종류 - 트리 간선 자식

- 이웃의 방문 번호가 0이면, 아직 탐색 되지 않은 노드. 이웃 노드의 부모 노드를 현재 노드로 설정하고, 이웃 노드에서 재귀호출. 해당 간선은 방문 트리에 속한 간선.

# 이웃 노드의 종류 - 트리 간선 부모

- 이웃 노드가 현재 노드의 부모 노드라면, 해당 간선은 트리 간선으로 부모 노드에서 이미 처리됨.

# 이웃 노드의 종류 - 빽 간선 조상

- 이웃 노드의 방문 번호가 더 작은데 부모 노드가 아니면, 해당 간선은 빽 간선. 방문 번호가 더 작으므로 조상 노드. 재귀호출은 할 필요 없음.

# 이웃 노드의 종류 - 빽 간선 후손

- 이웃 노드의 방문 번호가 더 크면, 해당 노드는 이미 방문했고 부모 노드도 아니므로 빽 간선. 방문 번호가 크므로 이웃은 후손이고, 후손에서 간선이 이미 처리되었음.

# 간선을 리스트에 모으는 방법

- 트리 간선의 자식 노드를 보면, 트리 간선을 리스트에 추가.
- 빽 간선의 조상 노드를 보면, 빽 간선을 리스트에 추가.

# 끈끈한 그래프 모으기

- 트리 간선의 자식 노드나 빽 간선의 조상 노드를 보면, 간선을 스택에 추가.
- postorder: 빽 번호가 부모의 방문 번호 이상이면 부모로부터 간선까지를 스택에서 꺼내서 리스트에 모으기
