# Repository instructions

## User-owned lab sources

- Never modify any file named `lab.c` anywhere in this repository.
- Treat `lab.c` as a read-only reference maintained by the user.
- This includes formatting, indentation, comments, fixes, generated changes, and synchronization with textbooks or webpages.
- Apply requested textbook or webpage code formatting and comments only to the corresponding documentation or display sources. Do not copy those edits back into `lab.c`.

This standing user instruction was recorded on 2026-11-01.

- Never modify any file named `ppt_material.md`, `ppt_lab_material.md`, `ppt.md`, or `ppt_lab.md` anywhere in this repository.
- Treat these files as read-only references maintained by the user.
- This includes formatting, comments, fixes, generated changes, and synchronization with textbooks or webpages.

This standing user instruction was recorded on 2026-11-01.

## Interactive textbook visuals

- Size each visual to its tallest reachable state at the current width and language. Include feedback, wrapped text, and controls that appear on completion when determining that height.
- Reserve that height from the first frame through interaction, playback, and reset so the textbook content below stays in place. Use the space the tallest state actually needs and keep its contents visible without an internal scrollbar.
- Recalculate the height when the width, language, fonts, or text wrapping changes. If hidden content is used for sizing, keep it outside the accessibility tree and keyboard tab order.
