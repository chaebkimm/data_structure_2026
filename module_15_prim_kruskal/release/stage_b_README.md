# Stage B - Representation and Cognitive Pause

Open these files in order:

1. `representation_reveal.md`
2. `cognitive_pause.md`
3. `vocabulary.md`, only after the pause response is preserved

The reveal names the weighted, undirected graph representation and contrasts
a shortest route from one source with a minimum connection for every vertex.

The Cognitive Pause has exactly three targets:

1. representation and objective;
2. one Prim/Kruskal state comparison; and
3. one invariant or boundary prediction.

An **invariant** is a rule that must remain true while work proceeds. A
**boundary case** is an input at or near a stated limit.

Approved extended-time and asynchronous versions use the same targets.
