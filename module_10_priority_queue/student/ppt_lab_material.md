## 데이터가 우선순위를 갖는 큐

- 큐에서 데이터를 꺼낼 때 시간 순서 대신 우선순위 순으로 꺼낸다.
- 추가된 시간을 기록하지 않으므로 배열리스트처럼 0부터 size - 1까지 범위에 데이터를 저장한다.
- 우선순위를 비교할 방법도 저장한다.

## 우선순위 큐 C 코드

```c
enum { CAP = 10 };
int arr[CAP];
int size = 0;
int is_empty(void) { 
  return size == 0; 
}
```

## 새로운 C 문법: 함수 포인터

- 함수 포인터에는 함수를 저장할 수 있다.
- `void (*fp)();` 형식으로 이름 앞에 *을 쓰고 괄호를 쳐서 만든다.
- `fp = f;` 형식으로 함수 이름을 저장한다.
- `fp();` 형식으로 함수처럼 실행한다.

## 우선순위 비교 함수 C 코드

```c
int (*comp)(int x, int y);
void init_queue(int more(int x, int y)) {
  comp = more;
  size = 0;
}
```

## 우선순위 큐에 데이터 추가하기

- 가정: 지금까지 배열에 우선순위가 높은 순서로 저장해놨다.
- 큐가 비었을 때 이 가정은 참이다.
- 추가할 때는 기존 데이터와 앞에서부터 비교한다. 어떤 데이터보다 우선순위가 높으면 그 뒤 모든 데이터보다 높다.

## 우선순위 큐에 데이터 추가하기

- 추가할 데이터가 기존 데이터보다 우선순위가 높은 자리를 처음 발견하면 그 자리가 새로운 데이터의 자리다.
- 그 자리 이후에 있는 기존 데이터들을 뒤로 한 칸씩 이동해서 자리를 마련한 다음 새로운 데이터를 저장한다.

## 우선순위 큐에 데이터 추가하기

```c
void enqueue(int data) {
  int pos = 0;
  while (pos < size && 
        !comp(data, arr[pos])) {
    pos++;
  }
```

## 우선순위 큐에 데이터 추가하기

```c
  for (int i = size; i > pos; 
       i--) {
    arr[i] = arr[i - 1];
  }
  arr[pos] = data;
  size++;
}
```

## 우선순위 큐에서 데이터 꺼내기

- 가정: 배열의 0부터 size - 1 까지에 우선순위가 높은 순서로 데이터가 있다.
- 우선순위가 가장 높은 데이터는 처음 데이터이므로, 배열에서 삭제하고 데이터를 반환한다.

## 우선순위 큐에서 데이터 꺼내기

```c
int dequeue(void) {
  int most = arr[0];
  for (int i = 0; i < size - 1; 
       i++) {
    arr[i] = arr[i + 1];
  }
```

## 우선순위 큐에서 데이터 꺼내기

```c
  size--;
  return most;
}
```

## 로그 정보 저장하기

- 이차원 배열을 만들어서 유저마다 로그인 또는 로그아웃 한 시간들을 저장한다.
- 모든 유저가 로그인을 다섯번씩 했다고 가정한다

## 최신 로그인 정보 저장하기

- 처음에는 모든 유저가 처음 로그인 한 구간을 비교한다.
- 한 유저가 로그아웃하면, 그 유저는 다음 로그인 구간으로 업데이트한다.

## 로그 정보를 저장하는 C 코드

```c
int logs[CAP][10];
struct User {
  int in;
  int out;
  int epoch;
};
struct User users[CAP];
```

## 로그인 정보 초기값

- 모든 유저는 처음에 0번째 로그인 정보가 최신 정보다.
- 처음 로그인 시각은 로그의 인덱스 0에 저장되어 있고, 처음 로그아웃 시각은 로그의 인덱스 1에 저장되어 있다.

## 로그인 정보 초기화 C 코드

```c
void init_users(void) {
  for (int i = 0; i < CAP; i++){
    users[i].epoch = 0;
    users[i].in = logs[i][0];
    users[i].out = logs[i][1];
  }
}
```

## 다음 로그인 회차로 업데이트 하기

- i번째 로그인 정보는 로그에서 i * 2 인덱스에 있다.
- i번째 로그아웃 정보는 로그에서 i * 2 + 1 인덱스에 있다.
- 다음 로그인 정보가 없으면 오류 코드로 -1을 반환한다.

## 로그인 회차 업데이트 C 코드

```c
int next_epoch(int i) {
  int j = ++users[i].epoch * 2;
  if (j >= 10) { return -1; }
  users[i].in = logs[i][j];
  users[i].out = logs[i][j + 1];
  return 0;
}
```

## 가장 먼저 로그아웃 하는 유저

- 로그아웃 시간을 비교하는 함수를 만들어서 우선순위 큐를 초기화 하면 가장 먼저 로그아웃 하는 유저를 쉽게 알아낼 수 있다.

## 가장 늦게 로그인 하는 유저

- 최신 로그인 정보를 0번째 로그인 정보로 초기화한다.
- 모든 유저에 대해 반복하며 로그인을 가장 늦게 하는 유저를 찾는다.
- 처음에는 0이 가장 로그인이 늦었다고 가정하고, 1부터 차례로 비교해 본다.

## 로그아웃 시간 비교 함수 C 코드

```c
int earlier_out(int x, int y) { 
  return users[x].out < users[y]
         .out; 
}
```

## 모두 로그인한 시간 구하기

- 최신 로그에서, 가장 늦은 로그인 시각이 가장 이른 로그아웃 시각보다 더 전이면 가장 늦은 로그인 시각에 모두가 로그인 해 있다.

## 모두 로그인할 때까지 반복하기

- 가장 먼저 로그아웃 한 유저는 다음 로그인 회차로 업데이트 한다.
- 업데이트된 로그인 시간을 마지막 로그인 시간과 비교해 본다.
- 업데이트된 로그아웃 시간을 우선순위 큐에 반영해 첫 로그아웃 시간을 구한다.
