12주차 – 우선순위 큐 코드

## 목차

1. 데이터가 우선순위를 갖는 큐
2. 우선순위 큐에 데이터 추가, 삭제하기

4. 모두 접속할 계획인 시간 찾기

## 복습 - 우선순위를 갖는 큐

- 데이터를 꺼낼 때 우선순위 순서로 한다.
- 큐에서처럼 `front`와 `rear`로 관리한다.
- 데이터를 우선순위 순서로 저장하는 방식으로 구현해본다.
- 같은 우선순위면 순서가 상관없다.

## 새로운 C 문법: 함수 포인터

- 함수 포인터는 함수 주소를 저장하고, 이를 통해 실행할 수 있다.
- `반환타입 (*이름)(매개변수);` 형식으로 이름 앞에 `*`을 쓰고 괄호를 쳐서 만든다.
- 우선순위 비교 방식을 바꿀 수 있게 해준다.

## 우선순위 큐 C 코드

```c
enum { CAPACITY = 10 };
int arr[CAPACITY], front, rear;
int (*compare)(int x, int y);
void init_queue(int (*compare_fp)(int x, int y)) {
  front = 0;
  rear = -1;
  compare = compare_fp;
}
```

## 복습 - 우선순위 큐에 데이터 추가

- 가정: 배열 뒤쪽에 저장할 공간이 있다.
- 마지막 데이터부터 차례로 비교해 추가할 위치를 찾는다.  
- 동시에 기존 데이터를 이동해 자리를 마련한 뒤 데이터를 추가한다.
- 마지막 데이터 위치를 업데이트 한다.

## 우선순위 큐에 데이터 추가 C 코드

```c
void enqueue(int data) {
  int pos = rear + 1;
  while (pos > front && compare(data, arr[pos - 1])) {
    arr[pos] = arr[pos - 1];
    pos--;
  }
  arr[pos] = data;
  rear++;
}
```

## 복습 - 우선순위 큐 데이터 꺼내기

- 가정: 저장된 데이터가 존재한다.
- 우선순위가 가장 높은 데이터는 처음 데이터이므로, 처음 데이터를 꺼낸다.
- 처음 데이터 위치를 업데이트 한다.
- 꺼낸 자리는 다시 쓰지 않으므로 배열이 충분히 커야 한다.

## 우선순위 큐 데이터 꺼내기 C 코드

```c
int dequeue(void) { return arr[front++]; }
```

## 복습 - 전체 미팅 시간 정하는 문제

- 유저들이 각자 계획한 시간에 로그인과 로그아웃을 여러 번 반복한다.
- 미팅을 언제 할지 결정하기 위해 모든 유저가 접속할 가장 이른 시간을 찾는다.

## 데이터 저장 방식 디자인

- 전체 접속 계획은 이차원 배열에 저장한다. 
- 실제로 문제를 푸는데 필요한 현재 시간 기준 접속 현황은 따로 배열을 만들어서 관리한다.

## 전체 접속 계획 이차원 배열

- 유저마다 로그인 또는 로그아웃 할 시간들을 저장한다.
- 모든 유저가 같은 횟수만큼 저장한다.
- 시간은 `0`부터 시작하며, 시간의 흐름에 따라 증가하는 순서로 저장한다.

## 전체 접속 계획 이차원 배열 C 코드

```c
enum { IDS = 2, EPOCHS = 3 };
int logs[IDS][EPOCHS * 2] = {
  {5, 6, 8, 9, 11, 13},
  {2, 5, 7, 8, 12, 15}
};
```

## 접속 현황 배열

- 유저마다 로그인 시간, 로그아웃 시간, 몇번째 접속인지 정보를 저장한다.
- 처음에 `0`번째 접속 정보를 쓰므로, 전체 접속 계획 배열에서 로그인 시간은 인덱스 `0`에 있고, 로그아웃 시간은 인덱스 `1`에 있다.

## 접속 현황 배열 C 코드

```c
struct User {
  int on;
  int off;
  int epoch;
};
struct User users[IDS];
```

## 접속 현황 배열 초기화 C 코드

```c
void init_users(void) {
  for (int i = 0; i < IDS; i++) {
    users[i].epoch = 0;
    users[i].on = logs[i][0];
    users[i].off = logs[i][1];
  }
}
```

## 다음 로그인 회차로 업데이트 하기

- `epoch`번째 로그인 정보는 계획에서 `epoch * 2` 인덱스에 있다.
- `epoch`번째 로그아웃 정보는 계획에서 `epoch * 2 + 1` 인덱스에 있다.
- 다음 로그인 정보가 없으면 오류 코드로 `-1`을 반환한다.

## 로그인 회차 업데이트 C 코드

```c
int next_epoch(int i) {
  int t = ++users[i].epoch;
  if (t >= EPOCHS) { return -1; }
  users[i].on = logs[i][t*2];
  users[i].off = logs[i][t*2+1];
  return 0;
}
```

## 복습 - 미팅 시간 정하는 절차

절차 시작 전에 접속 현황 배열 초기화

1. 로그인 시간 기준 미팅 시간 제시
2. 먼저 가는 유저 찾기
3. 미팅 때까지 로그아웃 안 했으면 확정
4. 미팅을 못 했으면 먼저 간 유저 시간 정보 업데이트하고 3.을 다시 반복

## 복습 - 미팅 시간 제시

- 제일 늦게 오는 유저에 맞춘다.
- 처음에는 모든 유저의 로그인 시간을 비교해서 최대값을 구한다. 초기값은 시간이 시작하는 `0`을 쓴다. 
- 다음에는 누군가 먼저 갔다가 돌아오는 시간하고만 비교해 보면 된다.

## 미팅 시간 제시 C 코드

```c
int max_login_time(void) {
  int time_max = 0;
  for (int i = 0; i < IDS; i++) {
    if (users[i].on > time_max){
      time_max = users[i].on;
    }
  }
  return time_max;
}
```

## 복습 - 먼저 가는 유저 찾기

- 처음에는 큐에 모든 유저를 저장한다. 
- 큐의 우선순위를 로그아웃 순서로 해서 먼저 가는 유저가 큐에서 나오게 한다.
- 큐에 유저의 번호를 저장해도 된다. 비교할 때는 그 번호로 유저의 로그아웃 시간을 찾아본다.

## 로그아웃 시간 비교 함수

- 로그인 정보가 업데이트 되면, 다음에 누가 먼저 로그아웃 하는지 알아본다. 
- 우선순위 큐로 유저들의 로그아웃 순서를 비교해서 구할 수 있다.
- 로그아웃 시간 비교 함수를 만들어 우선순위 큐에 제공한다.

## 로그아웃 시간 비교 함수 C 코드

```c
int earlier_logout(int user_x, int user_y) { 
  return users[user_x].off 
         < users[user_y].off; 
}
```

## 새로운 C 문법: 함수의 주소

- 주소를 구할 때는 앞에 `&`를 붙인다.
- `&함수이름` 형식으로 함수의 주소를 구할 수 있다.

## 먼저 가는 유저 찾기 C 코드

```c
int first_logout_id(void) {
  init_queue(&earlier_logout);
  for (int i = 0; i < IDS; i++) {
    enqueue(i);
  }
  return dequeue();
}
```

## 복습 - 미팅 시간 확정하기

- 미팅 시간이 로그인 시간 기준으로 계산해서 제시되었으므로, 로그아웃 시간만 확인하면 된다.
- 먼저 가는 유저가 미팅 시간 후에 로그아웃 하면 미팅 시간을 확정한다.

## 복습 - 돌아오는 유저 업데이트

- 먼저 가는 유저가 다시 돌아올 계획이 없으면 미팅을 못 한다.
- 돌아온 유저가 미팅 시간 후에 오면 미팅 시간을 새 로그인 시간으로 바꾼다.
- 돌아온 유저는 큐에 다시 추가하고, 큐에서 먼저 가는 유저를 새로 꺼낸다.

## 미팅 시간 확정하기 C 코드

```c
int survey(void) {
  init_users();
  int mtime = max_login_time();
  int i = first_logout_id();
  
  while (mtime >= users[i].off) {
    if (next_epoch(i) == -1) {
      return -1;
    }
    if (users[i].on > mtime) {
      mtime = users[i].on;
    }
    enqueue(i);
    i = dequeue();
  }
  return mtime;
}
```
