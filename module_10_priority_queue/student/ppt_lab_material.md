## 복습 - 데이터가 우선순위를 갖는 큐

- 큐에서 데이터를 꺼낼 때 시간 순서 대신 우선순위 순으로 꺼낸다.
- 추가된 시간을 기록하지 않으므로 배열리스트처럼 `0`부터 `cnt - 1`까지 범위에 데이터를 저장한다.
- 우선순위를 비교할 함수도 저장한다.

## 새로운 C 문법: 함수 포인터

- 함수 포인터는 함수를 저장한다.
- 우선순위 기준을 나중에 정하게 해준다.
- `반환타입 (*이름)(매개변수);` 형식으로 이름 앞에 `*`을 쓰고 괄호를 쳐서 만든다.
- 다른 함수를 대입할 수 있고, 보통 함수처럼 실행할 수 있다.

## 우선순위 큐 C 코드

```c
enum { CAP = 10 };
int arr[CAP], cnt;
int (*comp)(int x, int y);
void init_queue(int (*f)(int x, int y)) {
  cnt = 0;
  comp = f;
}
```

## 복습 - 우선순위 큐에 데이터 추가하기

- 가정: 배열의 `0`부터 `cnt - 1` 까지에 우선순위가 높은 순서로 데이터가 있다.
- 우선순위 순서를 유지하려면 어느 위치가 적절할지 차례로 비교해 본다. 
- 기존 데이터들을 이동해서 자리를 마련한 뒤 데이터를 추가한다.

## 우선순위 큐에 데이터 추가하기

```c
void enqueue(int data) {
  int pos = cnt;
  while (pos > 0 
         && comp(data, arr[pos - 1])) { 
    pos--; 
  }
  for (int i = cnt; i > pos; 
       i--) {
    arr[i] = arr[i - 1];
  }
  arr[pos] = data;
  cnt++;
}
```

## 복습 - 우선순위 큐에서 데이터 꺼내기

- 가정: 배열의 `0`부터 `cnt - 1` 까지에 우선순위가 높은 순서로 데이터가 있다.
- 우선순위가 가장 높은 데이터는 처음 데이터이므로, 배열에서 삭제하고 데이터를 반환한다.

## 우선순위 큐에서 데이터 꺼내기

```c
int dequeue(void) {
  int most = arr[0];
  for (int i = 0; i < cnt - 1; 
       i++) {
    arr[i] = arr[i + 1];
  }
  cnt--;
  return most;
}
```

## 복습 - 로그인 계획 저장하기

- 이차원 배열을 만들어서 세 유저마다 로그인 또는 로그아웃 할 시간들을 시간순으로 저장한다.
- 모든 유저가 로그인을 세 번씩 할 계획이 저장되어 있다.

## 로그인 계획을 저장하는 C 코드

```c
enum { USERS = 3, EPOCHS = 3 };
int logs[USERS][EPOCHS * 2] = {
  {5, 6, 8, 9, 11, 13},
  {2, 5, 7, 8, 12, 15},
  {1, 3, 5, 7, 9, 14}
};
```

## 현재 로그인 정보 저장하기

- 처음에는 모든 유저가 처음 로그인 한 구간을 비교한다.
- 시간이 지나 한 유저가 로그아웃하면, 그 유저는 다음 로그인 구간으로 업데이트한다.

## 현재 로그인 정보를 저장하는 C 코드

```c
struct User {
  int in;
  int out;
  int epoch;
};
struct User users[USERS];
```

## 현재 로그인 정보 초기값

- 모든 유저는 처음에 `0`번째 로그인 정보가 최신 정보다.
- 처음 로그인 시각은 계획의 인덱스 `0`에 저장되어 있고, 처음 로그아웃 시각은 계획의 인덱스 `1`에 저장되어 있다.

## 현재 로그인 정보 초기화 C 코드

```c
void init_users(void) {
  for (int id = 0; id < USERS; id++){
    users[id].epoch = 0;
    users[id].in = logs[id][0];
    users[id].out = logs[id][1];
  }
}
```

## 다음 로그인 회차로 업데이트 하기

- `epoch`번째 로그인 정보는 계획에서 `epoch * 2` 인덱스에 있다.
- `epoch`번째 로그아웃 정보는 계획에서 `epoch * 2 + 1` 인덱스에 있다.
- 다음 로그인 정보가 없으면 오류 코드로 `-1`을 반환한다.

## 로그인 회차 업데이트 C 코드

```c
int next_epoch(int id) {
  int t = ++users[id].epoch;
  if (t >= EPOCHS) { return -1; }
  users[id].in = logs[id][t * 2];
  users[id].out = logs[id][t * 2 + 1];
  return 0;
}
```

## 복습 - 미팅 시간 정하기

- 미팅 시간은 유저들 중 제일 나중에 로그인 하는 시간으로 잡는다.
- 누가 제일 먼저 로그아웃 하는지 체크한다.
- 로그아웃 시간이 미팅 시간 후면 미팅이 가능하다.
- 누군가 먼저 로그아웃 하면 다음 로그인 정보로 업데이트하고 다시 반복한다.

## 로그아웃 시간 비교 함수

- 로그인 정보가 업데이트 되면, 다음에 누가 먼저 로그아웃 하는지 알아봐야 한다. 
- 우선순위 큐의 유저들 우선순위를 로그아웃 순으로 관리하면 기존에 비교해 놓은 결과를 재사용할 수 있다.
- 로그아웃 시간 비교 함수를 만들어 쓴다.

## 로그아웃 시간 비교 함수 C 코드

```c
int earlier_out(int user_x, int user_y) { 
  return users[user_x].out 
         < users[user_y].out; 
}
```

## 미팅 시간 정하는 함수

1. 현재 로그인 정보를 초기화한다.
2. 미팅 시간을 정해 본다.
3. 먼저 로그아웃 하는 유저를 찾는다.
4. 미팅 시간까지 아무도 로그아웃 하지 않았으면 확정한다.
5. 누군가 로그아웃 했으면 정보를 업데이트하고 2.부터 반복한다.

## 미팅 시간 구하기

- 가능한 미팅 시간은 현재 유저들의 로그인 계획 중 가장 늦은 로그인 시간이다.
- 첫 미팅 시간은 모든 유저들의 로그인 계획 시간과 비교해서 찾는다.
- 로그인 시간이 항상 `0`보다 크다고 가정하면, 첫 미팅 시간의 초기값을 `0`으로 쓸 수 있다.
- 나중에 누군가 로그아웃하면 그 유저의 다음 로그인 시간만 확인해보면 된다.

## 미팅 시간 구하는 C 코드

```c
  /* 2. 미팅 시간 후보 */
  int meeting_time = 0;
  for (int id = 0; id < USERS; id++){
    if (meeting_time 
        < users[id].in) {
      meeting_time = users[id].in;
    }
  }
```

## 가장 먼저 로그아웃 하는 유저

- 우선순위 큐의 비교 함수를 로그아웃 시간 비교 함수로 설정한다.
- 우선순위 큐에 모든 유저의 번호를 저장한다. 
- 우선순위 큐에서 유저를 꺼내면 가장 먼저 로그아웃 하는 유저가 나온다.

## 새로운 C 문법: 함수를 인자로 쓰기

- C에서는 함수 이름을 쓰면 함수 포인터로 자동으로 변환된다.
- 따라서 매개변수가 함수 포인터인 경우 인자로 함수 이름을 적어도 된다.
- `init_queue(earlier_out);` 처럼 쓰는 것이 가능하다.

## 가장 먼저 로그아웃 하는 유저 구하는 C 코드

```c
  /* 3. 로그아웃 유저 */
  init_queue(earlier_out);
  for (int id = 0; id < USERS; id++){
    enqueue(id);
  }
  int out_id = dequeue();
```
