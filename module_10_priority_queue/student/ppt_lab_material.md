## 데이터가 우선순위를 갖는 큐

- 큐에서 데이터를 꺼낼 때 시간 순서 대신 우선순위 순으로 꺼낸다.
- 추가된 시간을 기록하지 않으므로 배열리스트처럼 `0`부터 `cnt - 1`까지 범위에 데이터를 저장한다.
- 우선순위를 비교할 함수도 저장한다.

## 새로운 C 문법: 함수 포인터

- 함수 포인터는 함수를 저장한다.
- 우선순위 기준을 나중에 정하게 해준다.
- `반환타입 (*이름)(매개변수);` 형식으로 이름 앞에 `*`을 쓰고 괄호를 쳐서 만든다.
- 다른 함수를 대입할 수 있고, 보통 함수처럼 실행할 수 있다.

## 우선순위 큐 C 코드

```c
int arr[10], cnt;
int (*comp)(int x, int y);
void init_queue(int (*f)(int x, int y)) {
  cnt = 0;
  comp = f;
}
```

## 우선순위 큐에 데이터 추가하기

- 가정: 배열의 `0`부터 `cnt - 1` 까지에 우선순위가 높은 순서로 데이터가 있다.
- 우선순위 순서를 유지하려면 어느 위치가 적절할지 차례로 비교해 본다. 
- 기존 데이터들을 이동해서 자리를 마련한 뒤 데이터를 추가한다.

## 우선순위 큐에 데이터 추가하기

```c
void enqueue(int data) {
  int pos = cnt;
  while (pos > 0 && comp(data, arr[pos - 1])) { pos--; }
  for (int i = cnt; i > pos; i--) {
    arr[i] = arr[i - 1];
  }
  arr[pos] = data;
  cnt++;
}
```

## 우선순위 큐에서 데이터 꺼내기

- 가정: 배열의 `0`부터 `cnt - 1` 까지에 우선순위가 높은 순서로 데이터가 있다.
- 우선순위가 가장 높은 데이터는 처음 데이터이므로, 배열에서 삭제하고 데이터를 반환한다.

## 우선순위 큐에서 데이터 꺼내기

```c
int dequeue(void) {
  int most = arr[0];
  for (int i = 0; i < size - 1; 
       i++) {
    arr[i] = arr[i + 1];
  }
```

## 우선순위 큐에서 데이터 꺼내기

```c
  size--;
  return most;
}
```

## 로그 정보 저장하기

- 이차원 배열을 만들어서 유저마다 로그인 또는 로그아웃 한 시간들을 시간순으로 저장한다.
- 모든 유저가 로그인을 다섯번씩 했다고 가정한다.

## 최신 로그인 정보 저장하기

- 처음에는 모든 유저가 처음 로그인 한 구간을 비교한다.
- 한 유저가 로그아웃하면, 그 유저는 다음 로그인 구간으로 업데이트한다.

## 로그 정보를 저장하는 C 코드

```c
int logs[CAP][10];
struct User {
  int in;
  int out;
  int epoch;
};
struct User users[CAP];
```

## 로그인 정보 초기값

- 모든 유저는 처음에 0번째 로그인 정보가 최신 정보다.
- 처음 로그인 시각은 로그의 인덱스 0에 저장되어 있고, 처음 로그아웃 시각은 로그의 인덱스 1에 저장되어 있다.

## 로그인 정보 초기화 C 코드

```c
void init_users(void) {
  for (int i = 0; i < CAP; i++){
    users[i].epoch = 0;
    users[i].in = logs[i][0];
    users[i].out = logs[i][1];
  }
}
```

## 다음 로그인 회차로 업데이트 하기

- epoch번째 로그인 정보는 로그에서 epoch * 2 인덱스에 있다.
- epoch번째 로그아웃 정보는 로그에서 epoch * 2 + 1 인덱스에 있다.
- 다음 로그인 정보가 없으면 오류 코드로 -1을 반환한다.

## 로그인 회차 업데이트 C 코드

```c
int next_epoch(int i) {
  int j = ++users[i].epoch * 2;
  if (j >= 10) { return -1; }
  users[i].in = logs[i][j];
  users[i].out = logs[i][j + 1];
  return 0;
}
```

## 복습 - 모두 로그인한 시간 찾는 법

- 최신 로그인, 로그아웃 정보를 0번째 정보로 초기화한다.
- 누가 제일 먼저 로그아웃 하고, 누가 제일 나중에 로그인 하는지 체크한다.
- 누군가 로그아웃 하고 나면 다음 로그인 정보로 업데이트 한다.

## 로그아웃 시간 비교 함수

- 누군가 로그아웃을 하고 로그인 정보가 업데이트 되면, 다음에 누가 로그아웃 하는지 알아봐야 한다. 
- 우선순위 큐의 유저들 우선순위를 로그아웃 순으로 관리하면 편하다.
- 로그아웃 시간 비교 함수를 쓰면 된다.

## 로그아웃 시간 비교 함수 C 코드

```c
int earlier_out(int user_x, int user_y) { 
  return users[user_x].out 
         < users[user_y].out; 
}
```

## 가장 먼저 로그아웃 하는 유저

- 우선순위 큐의 비교 함수를 로그아웃 시간 비교 함수로 설정한다.
- 우선순위 큐에 모든 유저의 번호를 저장한다. 
- 우선순위 큐에서 유저를 꺼내면 가장 먼저 로그아웃 하는 유저가 나온다.

## 새로운 C 문법: 함수를 인자로 쓰기

- C에서는 함수 이름을 쓰면 함수 포인터로 자동으로 변환된다.
- 따라서 매개변수가 함수 포인터인 경우 인자로 함수 이름을 적어도 된다.
- init_queue(earlier_out); 처럼 쓰는 것이 가능하다.

## 첫 로그아웃 유저 구하는 C 코드

```c
  init_queue(earlier_out);
  for (int i = 0; i < CAP; i++){
    enqueue(i);
  }
  int gone = dequeue();
```

## 가장 늦게 로그인 하는 유저

- 유저 0이 가장 늦게 로그인 했다고 가정하고 유저 1부터 비교해서 찾는다.
- 어떤 유저의 로그인 정보가 업데이트 된다면, 기존의 가장 늦게 로그인 하는 유저와 비교해서 가장 늦게 로그인 하는 유저를 업데이트한다.

## 마지막 로그인 유저 구하는 C 코드

```c
  int late = 0;
  for (int i = 1; i < CAP; i++){
    if (users[i].in 
        > users[late].in) {
      late = i;
    }
  }
```

## 모두 로그인한 시간 구하기

- 최신 로그에서, 가장 늦은 로그인 시각이 가장 이른 로그아웃 시각보다 더 전이면 가장 늦은 로그인 시각에 모두가 로그인 해 있다.

## 모두 로그인한 시간 구하는 C 코드

```c
  while (users[late].in
        >= users[gone].out) {
    ...
  }

}
```

## 로그아웃 한 유저 정보 업데이트

- 로그아웃 한 유저의 로그인 정보는 다음 로그인 회차로 업데이트 한다. 
- 새 로그인 시간을 기존 마지막 로그인과 비교해 마지막 로그인 유저를 구한다.
- 업데이트된 유저를 우선순위 큐에 다시 추가하고, 첫 로그아웃 유저를 꺼낸다.
