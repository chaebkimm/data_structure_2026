# 그래프 형태의 자료구조

- 리스트는 앞에 1개, 뒤에 1개, 순서 보존, 모두 연결됨
- 트리는 앞에 1개, 뒤에 여러개, 순서 보존, 모두 연결됨
- 그래프는 제약 없음

# 노드와 간선

- 트리에서와 같이 데이터와 관련 정보를 모아놓은 것을 노드라고 한다.
- 노드 간의 연결 정보를 간선이라고 한다. 간선에서는 출발 노드와 도착 노드로 방향성을 부여할 수 있다.

# 노드에 대한 통계

- 노드에서 나가는 간선의 개수
- 노드로 들어오는 간선의 개수
- 노드에 연결된 노드의 개수

# 그래프를 저장하는 방법

- 그래프 데이터와 간선 정보를 같이 저장한다.
- 간선 정보는 도착 노드들에 대한 리스트로 저장할 수 있다.
- 노드들도 리스트에 저장한다.

# 노드와 간선을 그래프에 추가하기

- 노드는 노드 리스트에 추가한다. 기존 노드 번호를 바꾸지 않기 위해 제일 끝에 추가한다.
- 간선은 시작 노드의 간선 리스트에 추가한다.

# 간선 삭제하기

- 간선의 시작 노드에 있는 간선 리스트에서 찾아서 삭제한다.

# 노드 삭제하기

- 먼저 간선 리스트를 모두 삭제한다. 해당 노드가 도착 노드인 간선도 모두 찾아서 삭제한다.
- 노드 리스트에서 노드를 삭제한다.

# 그래프에서 반복하기

- 노드 리스트에 있는 모든 노드들에 대해서 한 번씩 반복한다.
- 각 노드마다 간선 리스트에 있는 간선들에 대해서 한 번씩 반복한다.

# 무방향 그래프 예제

- 방향이 없는 그래프는 모든 간선에 대해 반대 방향의 간선이 항상 존재한다.

# 직간접적으로 연결된 노드 탐색

- 배열: 연결된 노드 표시
- 함수 연결된 노드 찾기(노드 n):
- 배열에 n 표시
- n에서 시작하는 간선들에서 반복:
-  도착 노드가 배열에 없으면 재귀 호출하기

# 탐색 과정에서 만들어지는 트리

- 처음 탐색을 시작한 노드가 루트다.
- 한 노드에서 이어진 노드를 새로 탐색하면 부모 자식 관계가 형성된다. 해당 간선을 트리 간선이라고 한다.
- 나머지 간선들은 이미 탐색된 노드에 연결된 빽간선들이다.

# 탐색 번호 매기기

- 처음 탐색을 시작한 노드는 0번이다.
- 간선으로 이어진 노드를 새로 탐색할 때마다 번호를 하나 늘려서 매긴다.
- 탐색 트리의 부모 노드는 항상 자식 노드보다 번호가 탐색 번호가 작다.

# 빽 번호 매기기

- 자신이나 자손의 빽간선을 최대 한번 거쳐 도달할 수 있는 최소 탐색 번호다.
- 자신이나 자손에 빽간선이 없으면 자신의 탐색 번호다.
- 빽 번호가 자신의 탐색 번호보다 작으면 어떤 사이클에 속해있다.

# 빽 번호와 부모 노드 번호

- 빽 번호가 부모 노드보다 크거나 같은 경우 부모 노드보다 루트에 가까운 노드로 가는 빽 간선이 없다.

# 이중으로 연결된 노드 그룹

- 그룹 내의 임의의 두 노드는 서로 다른 간선 세트를 통해 이어진다.
- 또는 그룹이 간선 하나로 이뤄진다.
- 그래프의 간선 집합은 이중 연결 그룹들로 분리할 수 있다.

# 컷 노드

- 이중 연결 그룹들의 교점
- 연결된 그래프에서 컷 노드를 제거하면 연결된 그래프 여러개로 쪼개진다.
- 자식 노드의 빽 번호가 부모 노드 번호보다 크거나 같으면 부모 노드가 컷 노드가 된다.

# 이중 연결 슈퍼 노드

- 이중 연결 그룹을 하나의 슈퍼 노드로 바꾸면, 그래프는 슈퍼 노드와 컷 노드들로 표현된다.
- 슈퍼 노드와 컷 노드들은 트리를 형성한다.
