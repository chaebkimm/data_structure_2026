# Module 3 — Stage B: Directed Matrix and Cognitive Pause

Open this stage only after preserving Stage A. Use
`representation_reveal.md`, then complete exactly three targets in
`cognitive_pause.md` before opening `vocabulary.md`.

After preserving the pause response and completing calibration, use the 30
required terms in `vocabulary.md`. Save its supplemental textbook terms for
Stage D, after the Stage C attempt is saved.

The model uses the same seven-account SNS follower network as Stage A, with
an arrow from follower to followed account. The five-minute pause asks you to
orient selected active rows 0, 2, and 6, trace the removal of `2 -> 3` by
writing the new row 2 and its out-degree, and classify three additions by
the self-loop and active-index rules.
Preserve your response before calibration. Approved extended-time formats
use the same targets.
