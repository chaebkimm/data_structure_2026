# Module 15 Vocabulary

- **Allocation:** storage reserved while a program runs.
- **Algorithm:** a defined sequence of steps for solving a problem.
- **Algorithmic-complexity denial of service:** valid attacker-chosen input
  causes an operation to perform far more work than expected.
- **AVL tree:** a Binary Search Tree whose balance factor at every node is
  `-1`, `0`, or `1`.
- **Assertion:** a test check that must be true.
- **Balance factor:** left-subtree height minus right-subtree height.
- **Binary Heap:** a priority structure that keeps a
  parent-before-children rule, not whole-subtree search order.
- **Binary Search Tree (BST):** a binary tree with every left-subtree key
  smaller and every right-subtree key larger than the node key.
- **Binary tree:** a branching structure with at most two children per
  node.
- **Child:** a node directly below another node.
- **Comparison:** one test that orders or matches two keys.
- **Complexity:** how resource use grows as input size grows.
- **Denial of service:** preventing or delaying intended service.
- **Edge height:** the number of links on a longest downward route;
  `height(NULL)=-1` and `height(leaf)=0`.
- **Invariant:** a rule that must hold for every valid state.
- **Inorder traversal:** visit left subtree, current node, then right
  subtree.
- **Interface:** operation declarations made available to other files.
- **Key:** the value used to order and find a record.
- **Leaf:** a node with no children.
- **Memory corruption:** an invalid memory read, write, or release.
- **Memory leak:** owned allocated storage that can no longer be reached
  and released.
- **Metadata:** values that describe other data, such as a node's height.
- **Memory address:** a number that identifies a storage location.
- **Node:** one stored record with a key, height, and links.
- **Ownership:** responsibility for releasing allocated storage.
- **Pointer:** a C value that stores a memory address.
- **Postcondition:** a rule guaranteed after a successful operation.
- **Precondition:** a rule the caller must satisfy before an operation.
- **Rebalance:** repair an AVL imbalance after a mutation.
- **Recursion:** an operation calls itself on a smaller part.
- **Regression test:** a test that checks a repaired defect does not return.
- **Relink:** change a pointer so it refers to a different object.
- **Resource exhaustion:** use up memory, storage, processing time, or
  another limited resource.
- **Root:** the first node of a tree or subtree.
- **Rotation:** a local relinking that changes tree shape while preserving
  inorder key order.
- **Sanitizer:** a runtime checker for defects such as invalid memory
  access.
- **Skewed:** shaped mostly as one long branch.
- **Stored height:** a node field holding that node's computed edge height.
- **Status:** the named outcome returned by an operation.
- **Test setup:** the data and state prepared before a test runs.
- **Strict unique-key policy:** equal-key insertion is rejected.
- **Subtree:** a node together with every node below it.
- **Traversal:** visiting nodes in a defined order.
- **Validator:** a diagnostic operation that reports whether invariants
  hold.
