# Module 2 — Stage B: Representation and Cognitive Pause

Open this stage after preserving your initial inquiry. Use
`representation_reveal.md` when directed and `vocabulary.md` as a reference.

The chapter stores character data and left/right indices in `nodes[20]`.
A missing child uses `-1`; index `0` remains valid. The five-node fixture
represents `1+2*3` with `'+'` at the root and `'*'` below its right side.

Complete the three targets in `cognitive_pause.md`: distinguish indices,
trace a term's reading position and root, and explain recursive evaluation.
The scheduled pause is five minutes. Approved extended-time or asynchronous
versions use the same targets. Preserve your response before calibration;
drawing quality, handwriting, and speed are not assessed.
