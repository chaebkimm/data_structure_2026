# Module 2 — Stage B: Representation and Cognitive Pause

Open this stage after preserving your initial inquiry. Use
`representation_reveal.md` when directed and `vocabulary.md` as a term
reference.

Then complete the three targets in `cognitive_pause.md`: read named child
positions, reason about a proposed cycle and the caller's responsibility,
and trace current-node/left/right search.

The revealed five-node fixture represents `(3 + 5) * 2` with preorder data
`'*', '+', 3, 5, 2`. Its binary operators have two operands, while the
underlying general binary-tree representation may validly use only one child
in other fixtures. After removing the plus branch, the remaining links are a
valid generic tree but not a completed binary expression.

The scheduled pause is five minutes. Approved extended-time or asynchronous
versions use the same targets. Preserve your response before calibration;
drawing quality, handwriting, and speed are not assessed.
