# Korean Data Structures Course Materials

Students read the textbook. The instructor uses the teaching guide in the same row to ask the first question and walk through the board examples. The required scope for the classes is decided by the [14-Week Delivery Guide](https://www.google.com/search?q=Data_Structures_Course_2026_14_Week_Delivery_Guide.md).

Before starting the course, first read about what data structures and efficiency mean in [How to Store Data Well](https://www.google.com/search?q=module_00_datastructure/textbook.md).
