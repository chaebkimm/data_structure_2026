# Module 14 - Stage A: Ordered Records Under Stress

Complete one initial prompt before opening later-stage materials.

- `inquiry_prompt.md` is the standard format.
- `inquiry_prompt_linear.md` presents the same records, arrival orders,
  questions, and scoring in a single reading sequence for assistive
  technology or sequential navigation.

Explore how a chosen arrangement behaves when numbered records arrive in
different orders. Preserve your first explanation before Stage B. Drawing
quality, speed, and specialized vocabulary are not assessed.
