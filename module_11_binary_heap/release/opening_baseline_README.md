# Optional Scan Baseline

The opening-baseline archive is superseded by the
[current lab release](release_manifest.md). The required Week 10 source is
[student/lab.c](../student/lab.c): a ten-integer min/max heap followed by a
ten-ID interval search using two heaps.

The [older scan Priority Queue package](../priority_queue_baseline/README.md)
is an optional reference for a different alert-record API. Its stable
arrival rule, allocation, statuses, and instrumentation do not describe
the current lab or add required implementation work.
