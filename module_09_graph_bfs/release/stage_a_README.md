# Module 9 — Stage A: Fewest Links Without Repetition

Complete one initial prompt before opening later-stage materials.

- `inquiry_prompt.md` is the standard format.
- `inquiry_prompt_linear.md` has the same targets in a linear format for a
  screen reader—software that reads on-screen text aloud—keyboard
  navigation, or speech input.

Invent a rule that starts at Gateway, handles systems requiring fewer links
before systems requiring more, prefers lower numbers at ties, remembers
waiting work immediately, and avoids repeats when routes merge or loop.
Preserve the inquiry before Stage B. Drawing quality and speed are not
assessed.
