# Module 12 — Stage B: Representation and Cognitive Pause

Open [representation_reveal.md](../student/representation_reveal.md) when
directed. It connects the record model to node IDs, missing links, a binary
search tree, edge-height, balance factor, and AVL rotations.

Complete the three targets in
[cognitive_pause.md](../student/cognitive_pause.md) before calibration,
which means comparison with the reference model. Preserve the response
before opening [vocabulary.md](../student/vocabulary.md). An approved
extended-time or separately scheduled response uses the same examples and
targets. Speed and drawing quality are not assessed.
